# ADR-0001：新仓库作为从零实现边界

## 状态

已接受（2026-09-19）。

## 背景

旧本地工作区混有未提交的重构实验，而远端主分支是另一套代码。继续在旧目录
渐进修改会把未完成的兼容假设带入新实现，也很难判断某个文件是否属于正式
发布版本。

## 决策

创建 `nonebot_plugin_xiuxian_3` 作为独立 GitHub 仓库和本地工作目录。首提交
只放规格文档、决策记录和忽略规则。旧主分支作为行为参考，新的代码、schema、
测试和资源从空仓库重新设计。

## 后果

- 可以独立选择领域模型、依赖和目录，不受旧 import/API 污染。
- 需要额外编写行为清单和数据迁移工具，不能依赖复制文件快速“完成”。
- 兼容命令、旧 URL 和历史数据必须在文档中明确，再按阶段实现。
