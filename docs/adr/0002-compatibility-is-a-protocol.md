# ADR-0002：兼容外部协议，不兼容内部实现

## 状态

已接受（2026-09-19）。

## 决策

兼容范围限定为用户可观察的协议：命令/别名、参数语法、权限、关键状态流转、
资产结果、Web 路径（明确保留的部分）、适配器场景和可恢复语义。旧模块路径、
类名、数据库表名、消息模板实现、随机算法和 import 副作用不属于兼容承诺。

所有兼容入口通过 manifest 和 adapter shim 指向新 application；shim 有命中
指标、目标版本和删除条件。

## 原因

内部兼容会把旧项目的耦合、隐式事务和导入顺序带入新项目，抵消从零重构的价值。
协议兼容能保护玩家体验，同时允许新项目建立清晰的领域边界。

## 验收

每个兼容项必须有输入/输出 fixture、重复请求测试、失败路径和迁移/回滚记录。
连续一个完整发布周期无命中且历史数据已迁移、备份可恢复后，才可删除 shim。
