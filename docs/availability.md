# 当前可用能力

此页概述正式版本 `v0.1.53` 中的玩家能力。详细命令请先发送 `修仙帮助`，再按启程、修炼、探索、悬赏、生活或社交查看分类帮助。QQ 回复可按账号能力提供部分蓝字或按钮；文本命令始终可用。

## 角色成长

新角色可以完成寻仙、凡人引导、选择六大道途与辅修、修炼、逐层晋升、突破和恢复。当前境界从感气到渡劫均有内容与成长入口；不同区域、玩法和配方仍受境界、地点、任务、物品、声望及次数条件约束。

## 世界与冒险

开发分支新增山野地貌勘察：感气二层在近郊查溪崖石层，感气四层继续铁木根脉，聚气三层再查岩径古渠。每处三段现场查验，可选较费精力的稳妥做法或省力尝试；实际扣体力、精力，失败保留进度并等待重试间隔。`山野手札` 可查现场、条件与下一步，暂离、重启及内容关闭后仍可接续既有记录。首次完成取得有真实生产用途的木材、药草、铁石或阵砂，重复完成不发奖励。此内容尚未正式发布。

已完成勘察的玩家还可回访溪崖药根、倒木铁层与古渠砂窝。每处个人储量六格、每两小时恢复一格；留养取材耗一格、间隔五分钟，强采耗三格、间隔半小时且把下次恢复推迟至至少三小时后。`资源脉预览` 可只读查看储量与恢复时间；木材和止血草在青石镇制作护脉木楔，每枚养护补至多两格，每处每日两次、间隔十五分钟。奖励材料继续投入炼丹、木楔与护甲，储量及养护次数在重启后保留。此内容尚未正式发布。

开发分支新增三处古迹寻遗：完成当地地貌勘察、备好青石镇生产的勘掘行囊并抵达现场后，可进入溪崖旧窑、铁木旧匠棚或岩径水工坊。每趟实际消耗一份行囊、体力与精力，且必经现有真实守护战；胜利才带回陶盘残片、定向铜针或测水刻环，战败与超过24小时未结算均无残件且不退行囊。出发后60秒内取消可退回行囊和数值资源，超过窗口不能取消；准备取消也计入当日次数。三件残料与阵砂在青石镇制作可穿戴山河罗盘，穿戴属性按耐久纳入后续战斗；额外残件可交全天城镇委托换取灵石与名望，再投入下一趟行装。`寻遗预览` 显示发现门槛、物资与路线。QQ/OneBot 共用同一应用和回执；此开发分支内容尚未正式发布。

`v0.1.48` 新增装备修缮：在青石镇对具体装备实例使用 `装备修复预览 <实例编号>` 查看缺失耐久、品质材料与灵石成本，再用 `修复装备 <实例编号>` 确认。完整修复成本按实际缺失耐久步数向上取整；破损装备修复后收纳，已穿戴装备保留原槽位、词条与祭炼等级。修缮消耗由装备成长档案配置。

`v0.1.48` 新增旧器回收：从 `我的装备` 选择已卸下的具体实例，使用 `装备回收预览 <实例编号>` 查看按品质成长档案计算的材料，再用 `回收装备 <实例编号>` 确认。回收只归档实例，不返还词条或祭炼投入；材料进入现有开放配方，破损装备也可回收。

`v0.1.48` 新增野外修缮闭环：在青石镇用铁石与木材，或铁石与止血草，制作 `野外修缮包`；使用 `野外修缮预览 <实例编号>` 查看一次修缮的定量恢复，再用 `野外修缮装备 <实例编号>` 在行途中消耗一包。每包最多恢复 2000 bp，破损装备恢复为未穿戴的可用实例，并保留词条与祭炼；战斗、生产和其他长时行动进行中不可修缮。多余修缮包可接取 `修缮包回收` 城镇委托换取灵石与名望。

开发分支开放近郊巡路、铁木巡林与岩径巡标，分别要求感气二层、感气四层与聚气三层。每条每日四次、三种加权事件，可选稳行或追迹；耗时、体力精力和遇战率不同，真实战斗胜利后才带回冻结收成。`巡查预览` 可查看人物、路况与材料用途，事件不要求线性剧情。此内容尚未正式发布。

玩家可以按地图条件移动，在开放地点进行采集、历练、自动战斗和探索，接取并完成悬赏，进入已开放秘境，推进玄天主线、领域前线、虚空档案及其他已接入剧情线。开放范围还包括三界移动、阵营活动、终局挑战和多类图鉴记录；完成万兽山主线并取得妖界引路资格后，可继续妖界栖地回响的贸易口登记、真实狩猎取证和八小时夜值，也可在元婴十层完成第十三章守山定契后接十小时的万兽山守契夜巡尾声。玄天近郊还开放旧兽道同行与栖地巡护，灵泉谷开放拾穗、炊烟和分享三段泉边剧情；云城店铺回响要求真实入城与名望来源；铁木问工新增林间备料、桥基勘务和工具修缮三关，材料、派遣和委托均从既有公开消费者取得；聚气一层的玄武岩径水标回响新增真实抵达、八小时筛砂和成功水标勘务三关，复用既有地点、挂机与派遣消费者。新角色可从青石镇、近郊与引路任务开始，逐步解锁后续地点。

开发分支新增道源终局资格核验：当前赛季完成三项道源任务后，可用 `道源资格` 查看冻结目标、来源操作和剩余要求，再用 `领取道源资格` 原子写入 `access.final_heaven`。资格只消费本赛季已结算的合道挑战、公共项目奖励和师徒毕业记录；开始、失败、旧赛季、重复或伪造来源不会计入。此入口尚未包含在当前正式版本发布范围内。

## 挂机、生产与经营

`v0.1.50` 新增药畦换种三关：感气二层后真实归镇，在本关新播精耕止血草，充分照料收获换来的云纹稻种，再实际交付止血草供应。旧田、未充分照料和枯萎不推进剧情，重启后可从主线与我的灵田接续；完成后可积累名望租灵圃小院、继续种云纹稻。

`v0.1.50` 的云稻炊香接续田作与饭食：感气二层后，在灵圃小院新播并充分照料云纹稻，烹饪辅修新锅成功做饭并实际恢复资源，再交付公开委托云饭待客。租院仍需六十镇中名望与租金；旧田、旧锅、失败生产和零恢复均不替代对应目标。

`v0.1.50` 的灵叶守圃包含泉边识叶、疏枝养叶、圃夜交灯三关：实际灵泉采集、新播精耕灵叶并充分照料，领取第二关奖励后开放六小时灵泉守圃。护叶引露和理沟收砂有不同成本与收成，完整交班后再实交圃夜备材；取消、逾时和旧记录不推进目标。三条新剧情结算均有下一步入口；守圃解锁不会因重做剧情撤销。

`v0.1.51` 开放百草坡药棚「雨棚辨药、丹火济伤、留根归铺」三关：感气二层后前往百草坡完整采药，以两份止血草和一份粗糙灵米新炉炼成低阶疗伤丹，再于本关开始后在青石镇新接取并交付药棚救治；终关须新接并交付三份止血草供应。旧安排、逾时保底、失败生产、只接未交和关前接单不推进关卡。采药与灵泉拾穗均为四小时、每日一次；药棚公开订单从当日公示起十二小时内交付，实际成本、生产日限及失败返料见[使用指南](usage.md#百草坡药棚)。断线、重启或内容关闭后可按冻结快照恢复既有进度和合法回执；最终首通奖励与「药棚留根簿」图鉴同事务写入且只发一次。QQ 官方与 OneBot V11 共用主线、采药、生产和委托入口，消息降级经 SDK 模拟验证，未宣称真实账号投递验收。

`v0.1.52` 开放聚气四层的雾隐守灯三关：用公开木材和药草制作洞天验行牌，从灵泉谷入洞实际消耗凭证，本关新探索取得阵砂；再选择固灯筛砂或照壁辨叶，完整守过六小时；最后回谷新制基础聚灵阵，于终关开始后在青石镇新接并交付灯阵续灵。第一关核对本人的探索开始、结算与战斗终态，战败、旧炉、关前接单和逾时保底不推进；生产、闲居与公示委托的原成本、日限和十二小时截止不变，详见[使用指南](usage.md#雾隐守灯)。重启或关闭后合法既有进度按冻结快照恢复，最终首通奖励和「归谷续灯录」图鉴只记一次。QQ/OneBot 共用应用入口，未宣称真实账号投递验证。

`v0.1.53` 开放金丹一层的云舟候潮三关：从云城实到渡口，新试炼取得碎票，再完整候潮八小时，选择扶舷搬铁或护袋理砂；终关实际回到青石镇，本关新接并实交两份云铁、一份阵砂的候潮备材订单。支付或等候风暴后的合法新票能推进，返航、未结算、旧票、旧安排、逾时保底和关前接单不能替代。本人开始、风暴与结算流水严格核对，旧关卡仍按冻结合同恢复；最终首通与「候潮归航录」图鉴同事务只发一次。时长、成本、每日额度、风暴恢复与 UTC 公示截止见[使用指南](usage.md#云舟候潮)。QQ 官方与 OneBot 共用应用入口，消息降级由 SDK 模拟验证，未宣称真实账号投递验收。

闲居路线提供离线挂机及领取/逾时结算；个人生产、灵田、居所、公共项目、城镇委托、运输、派遣和服务各自使用公开来源和资格校验。配方和产出可用于装备、丹药、阵法、食物、工具与其他已开放消费者。市场、求购、拍卖、生产委托与虚空寄售按各自区域和规则开放；批量生产委托已开放疗伤丹与木纹剑的二至五份整批预览、发布、接取、交付、确认、取消、清理和恢复，QQ 与 OneBot 共用同一入口与结算结果。

开发分支新增近郊篝火营、铁木桥畔营、岩径避风营，分别安排四、六、八小时。明确选择饭食或疗伤丹方案后，真实扣除一份补给；六十秒内取消退回，逾时只收少量材料。完整交班可取得营地行记，木材、铁石、阵砂可在青石镇制作并穿戴巡山护甲，或交付巡营备材取得灵石与名望。此内容尚未正式发布。

## 战斗与社交

开发分支的巡查悬赏按境界加入现有每日随机榜：近郊、铁木林、岩径各有单程和双程合同。接单后新出发并成功结算才计次，旧行程、取消、逾时及战败不计；随机灵石、材料与名望在接单时确定，巡查材料可保留制作或交付。这些合同尚未正式发布。

自动战斗支持已开放的单人及队伍 PvE、个人竞技和组队竞技；训练傀儡与直接切磋为不改变资产的战斗体验。宗门、师徒、道侣、队伍、地方服务、联盟和本地周赛等入口依条件开放。

## 接入与边界

QQ 官方机器人与 OneBot V11 使用相同的游戏用例。QQ 可用 Markdown、蓝字与键盘呈现，也会按 AppID 能力降级为纯文本；OneBot 提供等价文本命令。Web 管理能力以运行配置和权限为准，不代表开放玩家写入口。

正式支付、跨服身份合并、跨服匹配与玩家资产转移不属于当前可用能力。记录在内容文件中的锁定项、设计范围或测试夹具不能单独作为开放依据；运行时仍会校验地点、境界、物品、许可和会话状态。
