# 功能目录

本目录把主分支观察到的用户能力改写成产品边界。表中的“首批”表示建议
优先实现，不表示其它能力会被永久删除。每个功能最终都要有自己的用例、
状态模型、仓储端口、迁移、命令适配器、测试和（若需要）Web blueprint。

## 基础、角色与成长

| 功能 | 用户可见行为 | 关键状态 |
|:--|:--|:--|
| 角色与信息 | 注册、我的 ID、修仙信息、图片状态、排行榜、更新日志 | 角色、等级、境界、灵根、修为、灵石、体力 |
| 签到与日常 | 修仙签到、鸿运、每日/周常任务、任务领奖 | 日期窗口、连续签到、次数、奖励领取标记 |
| 修炼 | 修炼、闭关/出关、灵石修炼、重置修炼状态、状态查看 | 修炼会话、冷却、经验、体力 |
| 突破与渡劫 | 普通突破、连续突破、心魔/天命/普通渡劫、药物辅助 | 境界、突破锁、渡劫阶段、失败后状态 |
| 炼体 | 炼体、灵石炼体、药浴、冲窍、炼体突破、结算 | 炼体境界、窍穴、药浴会话、资源消耗 |
| 轮回与前世 | 进入轮回、无限轮回、投胎、前尘记忆和排行 | 轮回印记、前世快照、重置资格 |
| 传承与虚神界 | 祈愿/抽卡、传承背包、合成/分解、虚神界探索与对决 | 卡池、卡片、投影、战斗会话 |

## 娱乐与外部服务

| 功能 | 能力 | 隔离要求 |
|:--|:--|:--|
| 媒体解析 | B 站、抖音、快手、微博、小红书、小黑盒、X、TikTok、Instagram、YouTube 等链接 | 超时、大小限制、SSRF 防护、缓存；失败不影响游戏事务 |
| WebDAV | 管理员绑定账号，用户浏览、查询信息和获取文件链接 | 凭据加密/脱敏，路径限制，按 QQ 隔离 |
| NewAPI | 多站点绑定、信息、签到、历史、自动签到和解绑 | Token 不回显，按 QQ 隔离，外部失败可重试 |
| 图片/音乐/番剧 | 随机图片、互动 GIF、点歌、今日番剧、番剧周表、番剧盲盒 | 外部依赖隔离，使用缓存和媒体投递门面 |
| 小游戏 | 五子棋、宝可梦图鉴/盲盒、脑筋急转弯、答案之书等 | 会话超时、并发限制、不可写核心资产 |

## 功能完成定义

任何一行能力在进入“已实现”前，必须补齐：主流程、失败/取消/过期流程、
权限、冷却/次数、随机池版本、资产流水、重复请求、跨适配器提示、隔离数据
测试和运维观测。只有帮助文案而没有状态与测试的命令不算完成。
