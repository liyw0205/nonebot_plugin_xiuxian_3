# 基础：道途与辅修

> **兼容概览，非权威。** 开发时先读[开发文档总入口](development-guide.md)，再进入[道途域](foundation/paths/)；当前状态以[当前开发状态](current-status.md)为准。

## 1. 结构

修仙 3 采用“公共境界 + 首要道途 + 辅修专精”的构筑结构：

- 公共境界表达世界实力和可进入内容。
- 首要道途决定战斗资源、技能标签和主要风险。
- 辅修决定生产、服务、洞府和生活玩法价值。
- 功法、装备、技能和关系提供局部构筑，不替代境界。

玩家可以有一个首要道途和一个主辅修方向。额外子类通过学习、委托、宗门或剧情逐步开放。

## 2. 体修

主题：肉身、气血、筋骨、近身战和承伤。

核心属性：体魄、气血上限、护体、破势、韧性。

优势：持续战、承伤、低资源战斗、突破容错。

限制：远程压制弱，位移和战场控制需要额外技能，恢复材料消耗较高。

首批内容：炼体姿态、战意、护体、近战技能、药浴、体魄材料和一次保命被动。

## 3. 法修

主题：灵力、术法、元素、距离和控制。

核心属性：灵力、法术强度、穿透、控制强度、施法效率。

优势：远程、爆发、区域技能和元素策略。

限制：灵力管理、蓄力和冷却明显；不设计绝对元素免疫。

首批内容：基础元素倾向、单体术法、范围术法、控制术法和灵力恢复。

## 4. 器修

主题：机关、法器、傀儡、阵械和准备时间。

核心属性：器械威能、机关速度、耐久、操控上限、结构强度。

优势：战场布置、自动化、控制和多单位协同。

限制：维护成本、部件损坏、准备时间和操控上限。

首批内容：本命法器、一个机关槽、耐久、部件改造和简单傀儡。

## 5. 魔修

主题：魔界力量、契约、欲念、侵蚀和代价换强度。

核心属性：魔性、侵蚀、欲念、契约强度、失控抗性。

优势：短期爆发、牺牲换收益、特殊契约和非标准恢复。

风险：侵蚀阈值、心魔事件、阵营敌对、失控和交易代价。

魔修不是固定邪恶阵营。玩家可以通过净化、契约管理和剧情选择控制风险。

## 6. 妖修

主题：血脉、形态、族群、领地和环境适应。

核心属性：血脉、妖力、野性、感知、化形稳定度。

优势：环境适应、感知、采集、形态切换和族群资源。

风险：化形稳定、血脉冲突、族群声望和区域敌对。

妖修可以选择兽形、半化形或人形。血脉提供技能标签和环境优势，但不直接决定最终强弱。

## 7. 辅修总则

辅修是稳定的生产和生活成长线，不是“没有战斗能力的职业”。生活玩家可以通过服务、委托、交易、宗门建设和洞府建设参与高阶内容。

### 7.1 炼丹

子类：采药、辨药、配方、药理、毒理、药浴、恢复丹、突破辅助丹和特殊丹。

关键变量：药材品阶、药性匹配、炉具、火候、丹师熟练度、失败率、产出数量和品质。

### 7.2 炼器

子类：采矿、锻造、法器、机关、符印、部件、维修、改造和装备鉴定。

关键变量：矿材纯度、结构强度、工艺、炉具、部件槽、耐久和改造风险。

### 7.3 布阵

子类：测绘、阵纹、结界、聚灵、传送、侦测、战斗阵和洞天建设。

关键变量：阵基、灵脉、覆盖范围、持续时间、维护成本和破解难度。

### 7.4 生活子类

采集、灵植、烹饪、钓鱼、驯兽、鉴定、商贸、运输、制香、酿造和机关维护均可作为子类。

生活子类必须有真实需求、生产限制和交付对象，不能只靠系统商店无限回收。

## 8. 道途切换

切换道途需要满足剧情、境界、资源或特殊事件条件。切换后：

- 历史技能和装备不一定全部失效。
- 道途专属状态可能冻结、转化或需要清理。
- 污染、血脉、契约和关系不能通过普通洗点删除。
- 切换记录保留在角色历史中，影响部分 NPC 和阵营判断。

## 9. 平衡原则

- 公共境界优先决定内容准入。
- 道途提供明显差异，但不应让一个道途在所有场景最优。
- 辅修通过经济和服务获得价值，不能无限制造核心货币。
- 魔修和妖修拥有代价与独特机会，不用简单善恶倍率平衡。
- 同一属性来源不重复进入多个乘区。

## 10. 实现合同

### 10.1 道途数据

`PathBuild` 保存：

| 字段 | 说明 |
|:--|:--|
| `player_id` | 角色唯一外键 |
| `path_key` | `body`、`spell`、`device`、`demonic`、`beast`、`support` |
| `path_level` | 道途熟练阶段，首版 1-5 |
| `active_traits` | 已激活被动键列表，必须引用内容定义 |
| `state_payload` | 道途状态结构，例如侵蚀、血脉、战意 |
| `switch_count` | 历史切换次数 |
| `last_switch_at` | 最近切换时间 |
| `rule_version` | 道途规则版本 |

`SubProfession` 保存 `subprofession_key`、等级、熟练度、已学配方、每日精力上限、生产统计和规则版本。配方定义不直接复制到玩家记录。

### 10.2 道途选择用例

输入：角色、道途键、选择来源、`operation_id`。

预检查：角色处于允许选择的阶段、道途内容已开放、未选择过首要道途或满足切换条件。

成功输出：道途键、初始被动、状态初始化、可用技能列表和规则版本。

错误码：`PATH_NOT_FOUND`、`PATH_ALREADY_SELECTED`、`PATH_LOCKED`、`PATH_REQUIREMENT_MISSING`、`PATH_SWITCH_COOLDOWN`、`PATH_STATE_CONFLICT`。

### 10.3 道途切换状态机

```text
unselected -> selected
selected -> switch_pending -> selected
selected -> frozen -> selected
```

切换采用“先计算计划、再确认扣费、最后应用”的两阶段流程。计划中列出会保留、冻结、转化和清理的技能、装备、状态和关系影响；玩家确认后才消耗资源。

切换失败或确认超时不改变角色。已应用切换不能通过重复请求回滚，除非使用专门的管理员恢复用例。

### 10.4 道途最低实现差异

| 道途 | 首版被动 | 首版主动 | 首版代价/限制 |
|:--|:--|:--|:--|
| 体修 | 体魄转气血效率 | 近身攻击 | 灵力技能少，恢复材料消耗 |
| 法修 | 灵力转法术效率 | 单体术法 | 灵力和冷却 |
| 器修 | 法器耐久效率 | 一件机关 | 耐久和操控上限 |
| 魔修 | 魔性短期转伤害 | 代价换爆发 | 侵蚀增长 |
| 妖修 | 环境感知 | 形态切换 | 化形稳定度 |
| 辅修 | 生产熟练度成长 | 生产/服务动作 | 精力和配方限制 |

### 10.5 验收样例

1. 玩家只能有一个首要道途，重复选择返回 `PATH_ALREADY_SELECTED`。
2. 道途选择失败时不写入被动、不扣资源、不增加切换次数。
3. 魔修动作增加侵蚀并写入状态流水；查询可以解释侵蚀来源。
4. 妖修切换形态只改变定义中的属性和可用动作，不重置公共境界。
5. 辅修生产熟练度只在生产 operation 成功结算后增加，重复结算不重复增加。
