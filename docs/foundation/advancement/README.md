# 核心：修炼与构筑养成域

本域负责闭关修行、天赋树、体质、技能成长、法器强化和洗练。玩法内容与可调数值由 `data/` 提供；数据库只保存角色状态、操作流水和结算快照。

当前开放闭关、体质、道脉、神通和低阶法器养成；生活挂机、灵兽成长和战斗属性实时修改仍
保持关闭，具体状态见[当前开发状态](../../current-status.md)。

## 术语映射

|:--|:--|:--|
| 修炼/挂机经验 | 闭关修行结算 | `progression.retreat` |
| 天赋树 | 道脉天书 | `talent.tree` |

## 关键边界

- 生活挂机 `specials.idle` 不产修为；只有 `progression.retreat` 是受限的闭关修行会话，可以产境内修为。
- 闭关收益按离线最大窗口、洞府/功法/精力/食物快照结算，每日上限，不能离线无限累积。
- 功法的修为倍率在开始修炼时冻结；战斗属性和反伤在开战时冻结。不同功法可以共享同品质的修为倍率，但战斗被动各有取向。
- 体质是角色构筑基底，首版从资格快照选择 1 个主质；重塑需要稀有契约和冷却，不能随意切换。
- 天赋/技能/祭炼/重铸均不能绕过十层准入，也不能把低阶资源转换为跨境突破材料。
- 强化是可控等级成长；洗练是有限词条重掷，历史结果和消耗必须保留。失败不静默销毁唯一装备。

## 实体

`RetreatSession`、`TalentNodeState`、`ConstitutionProfile`、`SkillMastery`、`TemperingRecord`、`RefinementRecord` 保存角色状态、操作快照、operation 与结果摘要；成本和成长规则不复制进数据库规则字段。

## 当前实现切片

当前已实现闭关修行的基础切片：`闭关预览`、`开始闭关`、`结算闭关`、`恢复闭关`，以及体质根性：
`体质预览`、`选择体质`、`我的体质`、`重塑体质`。
基础闭关使用 `progression.retreat.basic`，静养闭关使用 `progression.retreat.restful`；两者
均由独立 `retreat_sessions` 表和 operation ledger 持久化。静养所需的最小居所使用
`residence.town_room`，通过 `租住居所` 和 `我的居所` 管理。体质使用独立
`constitution_profiles` 表保存单一主质、效果、资格/道途快照和重塑冷却；道脉天书使用
`talent_node_states` 与天赋点流水保存当前首要道途的节点。神通参悟已接入
`skill_masteries` 与资源消耗流水，开放 `神通预览`、`我的神通`、`参悟神通 <技能>`；技能目录和基础效果从技能内容读取，等级上限、效果增长字段与分级成本从成长内容读取。技能记录只保存技能键和等级，战斗开始时依据内容包冻结当时的有效效果。
法器、防具和道途饰品共用 `equipment_instances`、祭炼流水和重铸流水。装备及成长来自
`data/装备/`；饰品按六大道途和九个开放境界提供不同战斗偏向。自动战斗冻结装备效果，
并消费配置的属性；单独穿脱槽位仍未开放。灵兽仍按内容开发总表逐个切片。
