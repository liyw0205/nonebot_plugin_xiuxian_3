# v0.2 修炼与构筑养成内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.2`，`rule_version=advancement-0.2.0`。金丹前后开放进阶闭关、第二体质方向（仍只能一主质）、天赋二阶、技能 4–6 级、法器强化 4–6、灵兽蜕变 I。

| 系统 | 稳定键/准入 | 成本与效果 |
|:--|:--|:--|
| 闭关 | `progression.retreat.foundation`：筑基 L1 | 4h、精力 8、灵米 2；修为 260–340；每日最多 2 |
| 天赋 | `talent.tree.*.tier2`：对应 L3 指导任务 | 3/5/8 点；效率/容量效果各 +2%–+4%，不加突破率 |
| 技能 | `skill.growth.tier2`：感气/聚气技能 4–6 | 灵石 100/150/220、技能心得 2/3/4；成功 100% |
| 祭炼 | `item.tempering.core`：金丹 L1 或核心法器 | 强化 4–6，成功 80/70/60%；失败等级不降、耐久 -100 bp |
| 重铸 | `item.refinement.core` | 2 词条池、锁 1 词条需额外灵石；失败保旧词条 |
| 灵兽 | `beast.evolution.wood_rat_1`：等级 10、亲和 40 | 灵果 3、灵石 300；成功 100%；采集发现率上限 +5% |
| 灵骑 | `mount.tack.cloud_saddle`：灵石 500、云布 2 | 移动耗时 -5%，耐力 30；损坏只失效 |

v0.2 不直接提供元婴突破物、领域能量或跨界终局资源。
