# v0.4 修炼与构筑养成内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.4`，`rule_version=advancement-0.4.0`。化神版本开放领域构筑，但不让天赋/技能/法器成长绕过 L10 混元突破。

| 系统 | 稳定键/准入 | 成本与效果 |
|:--|:--|:--|
| 闭关 | `progression.retreat.soul_transformation`：化神 L1 | 8h、精力 16；境内修为 1,200–1,600；每日 1 |
| 体质 | `constitution.domain_affinity`：领域许可 | 选择 1 个领域偏向，领域行动效率 +5%；不可与同类重复叠加 |
| 天赋 | `talent.tree.*.tier4`：化神 L3、前置节点 | 21/34/55 点；开放领域协同节点，单项效率上限 +8% |
| 技能 | `skill.growth.tier4`：技能 10–12 | 领域材料/技能心得；每级基础效果 +4%，不增加突破概率 |
| 祭炼 | `item.tempering.domain`：化神 L1 法器 | 强化 10–12，成功 45/40/35%；失败耐久 -500 bp，等级不降 |
| 重铸 | `item.refinement.domain` | 可锁 2 词条；每次消耗领域材料；失败保留旧词条并增加保底计数 |
| 灵兽 | `beast.evolution.domain`：阶段 II、亲和 75 | 领域材料 2、灵石 2,000；成功 80%；失败休养 6h，不降阶 |
| 灵骑 | `mount.evolution.domain`：灵骑等级 20 | 领域鞍具 1；移动/运输耗时 -10%，耐力 60；不增加战斗伤害 |

化神构筑只读领域快照；领域关闭时已开始的修炼/祭炼按原版本结算，不能重新抽取。
