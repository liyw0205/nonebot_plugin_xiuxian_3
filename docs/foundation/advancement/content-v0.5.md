# v0.5 修炼与构筑养成内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.5`，`rule_version=advancement-0.5.0`。炼虚版本开放虚空适应和高阶法器，但虚力、虚空锚与航道核心不是养成系统的可刷资源。

| 系统 | 稳定键/准入 | 成本与效果 |
|:--|:--|:--|
| 闭关 | `progression.retreat.void_refining`：炼虚 L1、虚空安全屋 | 8h、精力 20；修为 2,000–2,600；每日 1 |
| 体质 | `constitution.void_resistance`：完成虚空适应任务 | 选择 1 项虚空抗性 +500 bp；不可直接提高 `void_power` |
| 天赋 | `talent.tree.*.tier5`：炼虚 L3 | 34/55/89 点；开放虚空服务/航道协同，单项上限 +10% |
| 技能 | `skill.growth.tier5`：技能 13–15 | 虚空普通材料/技能心得；每级 +5%，不能改写战斗快照 |
| 祭炼 | `item.tempering.void`：炼虚 L1 | 强化 13–15，成功 30/25/20%；失败耐久 -800 bp，等级不降 |
| 重铸 | `item.refinement.void` | 可锁 3 词条；虚空词条池必须声明抗性/服务用途，不得出现飞升属性 |
| 灵兽 | `beast.evolution.void`：亲和 85、虚空适应 | 普通航道材料 3；成功 70%；失败进入休养 12h |
| 灵骑 | `mount.evolution.void`：灵骑等级 30 | 航道鞍具 1；航行耗时 -12%、耐力 80；虚空不稳定只读入快照 |

虚空养成失败不扣境界、不生成天劫债；唯一装备先锁定，回滚保留旧词条/旧强化。
