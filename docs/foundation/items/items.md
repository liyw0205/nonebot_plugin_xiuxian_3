# 物品域：内容和实例

## 内容定义

`item_key`、`item_type`、`quality`、`bind_type`、`stack_limit`、`effects`、`requirements`、`rule_version`、`content_version`。

物品类型：功法、配方、技能、法器、防具、机关、丹药、材料、特殊物品、奖励包、称号。

## 物品实例

唯一物品保存 `instance_id`、`item_key`、持有者、绑定状态、数量、耐久、强化/改造状态、来源 operation、创建时间和规则版本。

堆叠物品按角色、物品键、绑定类型和品质维度合并。宠物、傀儡和有独立成长的机关使用实体实例，不使用普通堆叠。

## 技能和效果

效果使用白名单类型和参数结构，不执行任意代码。技能定义目标、范围、资源、冷却、命中、基础值、缩放、状态和失败结果。
