# 资源域：资源模型

| 资源 | 类型 | 主要写入来源 | 主要消耗 |
|:--|:--|:--|:--|
| 修为 | 非负整数 | 修炼、探索、任务、战斗 | 境界层数和突破 |
| 灵石 | 钱包余额 | 任务、生产、市场、服务、常驻经营 | 配方、移动、维修、交易、居所维护 |
| 体力 | 当前/上限 | 周期恢复、奖励 | 探索、战斗、高风险行动 |
| 精力 | 当前/上限 | 周期恢复 | 生产、生活、委托 |
| 气血/灵力 | 快照资源 | 战斗、恢复 | 技能、损伤 |
| 材料 | 堆叠物品 | 采集、战斗、生产、灵田 | 配方、任务、交易、公共建设 |
| 声望 | 分阵营/地区整数 | 宗门、城市、事件、常驻经营 | 资格、兑换、关系、设施 |
| 服务信誉 | 0–100 整数 | 委托、运输、常驻服务 | 服务等级、押金、订单槽 |

每次变化写 `LedgerEntry`：资源键、角色、前值、变化量、后值、来源类型、来源 ID、规则版本和 operation ID。
