# 道途域：六大道途

| 道途 | 资源/状态 | 首版主动 | 主要限制 |
|:--|:--|:--|:--|
| 体修 | 体魄、战意、护体 | 近身攻击、护体 | 灵力技能少，恢复消耗 |
| 法修 | 灵力、元素、控制 | 单体/范围术法 | 灵力、蓄力、冷却 |
| 器修 | 器械威能、耐久 | 一件机关 | 耐久和操控上限 |
| 魔修 | 魔性、侵蚀、契约 | 代价换爆发 | 侵蚀、失控、阵营关系 |
| 妖修 | 血脉、妖力、化形 | 形态切换 | 化形稳定、族群关系 |
| 辅修 | 熟练度、配方、精力 | 生产和服务 | 配方、材料、精力 |

辅修主类为炼丹、炼器、布阵；采集、灵植、鉴定、烹饪、钓鱼、驯兽、商贸、运输和机关维护是子类。

每个道途首版只提供一个被动、一个主动和一个限制状态，避免第一版出现完整技能树。
