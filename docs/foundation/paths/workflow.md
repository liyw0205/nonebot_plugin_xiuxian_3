# 道途域：选择与切换状态机

```text
unselected -> selected
selected -> switch_pending -> selected
selected -> frozen -> selected
```

选择流程：读取当前内容并按稳定键、名称或别名解析 -> 检查阶段、道途开放状态、辅修必选关系和全部引用 ->
在同一事务中创建道途记录、发放入门所得、登记图鉴并写入选择 operation。锁定、歧义、坏字段或坏引用在
任何角色、资产、图鉴和 operation 写入前失败；QQ 官方与 OneBot V11 只调用同一 application。

成功 operation 保存稳定道途/辅修键和角色结果；同输入重放或重启先回放原结果，不重复发放。内容改名或删除
别名只影响新的文字选择，稳定键仍可回放，旧文字输入不增加兼容分支。

切换流程：生成计划 -> 展示保留/冻结/转化/清理项 -> 玩家确认 -> 锁定费用 -> 应用切换 -> 生成新属性快照。

首阶段切换已按本状态机接入：`path_switch_plans` 保存待确认/已确认/已取消/已过期计划，
`领取转修令` 提供一次性冷却令牌，`转修道途` 生成计划，`确认转修` 扣 500 灵石与令牌并更新
`path_key`/`subprofession_key`，`取消转修` 零扣取消。确认超时不扣资源；已应用切换不能通过
重复确认回滚；管理员恢复必须使用独立恢复用例。污染、血脉和契约不能通过普通洗点删除。
旧道脉、旧神通与旧装备不删除，新道途下按当前 `path_key` 冻结。

元婴重构复用同一状态机：`道途重构预览` 生成 24 小时计划，`确认道途重构` 在单事务扣 50000 灵石与
`item.token.rebuild_path`、更新 `path_key`/`subprofession_key`、写 `path_rebuilds` 并为目标树继承
`max(1, old_level - 2)` 个免费 `learned` 节点，`取消道途重构` 零扣取消。每名角色只允许一次；
预览过期或旧树等级变化不扣资产。确认后旧树保留并冻结，目标树已有节点不重复写入。
