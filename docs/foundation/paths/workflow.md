# 道途域：选择与切换状态机

```text
unselected -> selected
selected -> switch_pending -> selected
selected -> frozen -> selected
```

选择流程：读取当前内容并按稳定键、名称或别名解析 -> 检查阶段、道途开放状态、辅修必选关系和全部引用 ->
在同一事务中创建道途记录、发放入门所得、登记图鉴并写入选择 operation。锁定、歧义、坏字段或坏引用在
任何角色、资产、图鉴和 operation 写入前失败；QQ 官方与 OneBot V11 只调用同一 application。

成功 operation 保存稳定道途/辅修键和角色结果；同输入重放或重启先回放原结果，不重复发放。内容改名或删除
别名只影响新的文字选择，稳定键仍可回放，旧文字输入不增加兼容分支。

切换流程：生成计划 -> 展示保留/冻结/转化/清理项 -> 玩家确认 -> 锁定费用 -> 应用切换 -> 生成新属性快照。

切换确认超时不扣资源。已应用切换不能通过重复请求回滚；管理员恢复必须使用独立恢复用例。污染、血脉和契约不能通过普通洗点删除。
