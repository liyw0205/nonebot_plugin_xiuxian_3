# 基础：角色域

角色域负责平台身份、玩家生命周期、寻仙问道、凡人阶段、入道、改名和首次奖励。

## 子文档

- [数据模型](model.md)：Player、资质快照、引导和名称历史。
- [状态与流程](workflow.md)：新用户到修行者的状态机。
- [用例与验收](use-cases.md)：输入、输出、错误码和测试样例。
- [v0.1 内容快照](content-v0.1.md)：新手到入道在 `content-0.1` 中的稳定键、数值、奖励、失败、回滚和验收参数；完整裁决见 [完整内容开发总表](../../content-development.md)。

## 边界

角色域只负责身份和角色状态，不负责境界计算、道途效果、地图移动、消息发送和奖励具体内容。奖励通过统一奖励服务发放。

首版流程与数值裁决来源是[完整内容开发总表](../../content-development.md)：寻仙问道完成后进入 `mortal`，三项凡人引导完成后进入 `seeker`，首要道途选择成功后进入 `cultivator`。实现不得把“已注册”直接等同于凡人或修行者；`content-v0.1.md` 只保存历史快照。
