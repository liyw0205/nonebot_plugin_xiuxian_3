# 境界域：状态机

## 修炼

```text
idle -> running -> completed
idle -> rejected
running -> cancelled/expired/failed
```

## 突破

```text
ready -> preparing -> resolved_success
                  \-> resolved_failure -> recovery -> ready
ready -> tribulation -> resolved_success/resolved_failure
```

预检查包括境界、修为、材料、气血、灵力、地点、战斗锁和虚弱状态。失败应用虚弱、道基震荡、心魔或天劫残痕之一，具体由境界定义决定。
