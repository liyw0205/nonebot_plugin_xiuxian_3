# 基础：属性域

属性域负责基础属性、永久成长、已装备构筑、加成乘区、不可变快照和内容指纹。

- [属性模型](model.md)
- [计算生命周期](workflow.md)
- [公式、错误与验收](use-cases.md)

属性域不负责玩家资源扣除和战斗结算；它只生成只读预览和不可变快照。

`我的属性`、`我的状态`和普通战斗从同一构筑生成数值。纯规则
`build_stat_preview`不访问数据库；共享仓储读取角色、已穿戴装备、功法与体质后调用它。
战斗字段只把面板的`max_mp`映射为`max_mana`，不另设气血、灵力或先手公式。
天劫和终局保留明确的高阶场景映射，不能与普通面板数值混为一谈。
