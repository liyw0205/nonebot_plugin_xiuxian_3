# v0.3 属性内容基线：元婴神魂与跨界

本文件遵守 [版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.3`，`rule_version=stats-0.3.0`。

## 1. 元婴基础成长

元婴突破成功 operation 一次性增加：气血 +600、灵力 +480、负重 +50、探索效率 +1500 bp；不修改初始六维。该增量写入 `realm` 来源，不能被装备卸下或重构道途移除。

| `resource_key` | 初始/上限 | 恢复 | 获取 | 消耗 |
|:--|:--|:--|:--|:--|
| `soul_power` | 100 / 100 | 每日 +20，最高 100 | 元婴突破、心魔/跨界内容 | 魂压技能、跨界秘境复活、化神前置 |
| `world_merit` | 0 / 无硬上限 | 无 | 阵营战争、赛季、跨界事件 | 元婴突破、宗门/跨界许可 |
| `domain_charge` | 0 / 100 | 每日恢复至 100 | 元婴突破、事件奖励 | 元婴领域预览/技能；化神后替换为 150 上限 |
| `cross_realm_penalty_bp` | 1000 / 0 | 完成盟约后为 0 | 非本界地点自动计算 | 环境乘区惩罚，不是可交易资源 |

## 2. 跨界与神魂规则

非本界角色进入魔界/妖界时，默认 `environment_bp=-1000`。完成对应阵营盟约后该惩罚为 0；妖修在妖界、魔修在魔界也按内容定义享受相应道途修正，但不能同时消除其它世界惩罚。

跨界死亡：不降境界、不掉物品；扣当前神魂 2000 bp（向上取整，最少 1），并设置 `soul_exhaustion` 2 小时。神魂为 0 时拒绝跨界战斗、跨界秘境和元婴高风险技能，普通玄天界行动仍可进行。`soul_exhaustion` 不阻止资料读取或商城浏览。

## 3. 元婴快照与上限

`SoulSnapshot` 绑定战斗/探索，保存神魂、世界功勋、领域能量、环境惩罚、盟约、道途、地点、版本与来源。`soul_power` 不可借贷，`domain_charge` 不可跨日溢出；资源恢复是稳定 job，job run ID 与业务日共同幂等。

元婴临时增伤仍受 10,000 bp 总上限；跨界环境惩罚在环境乘区先结算，再应用临时加成，不能被普通增伤抵消。

## 4. 错误、关闭与验收

错误：`SOUL_POWER_INSUFFICIENT`、`SOUL_EXHAUSTION_ACTIVE`、`CROSS_REALM_ALLIANCE_MISSING`、`DOMAIN_CHARGE_INSUFFICIENT`、`RESOURCE_CAP_REACHED`。

关闭 v0.3 后停止新跨界会话和新资源恢复；已开始会话按快照结算。验收：每日恢复不超过上限且重复 job 不双加；非本界惩罚正确、盟约只消对应世界；死亡扣神魂一次；0 神魂动作拒绝不扣费用；历史战斗读取原环境快照。
