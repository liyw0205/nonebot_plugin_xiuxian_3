# 属性域：模型

## 基础属性

`body` 体魄、`spirit` 灵力、`insight` 悟性、`root` 根骨、`agility` 身法、`fortune` 气运。

## StatSnapshot

`snapshot_id`、`player_id`、`base_stats`、`path_stats`、`derived_stats`、`source_refs`、内容规则指纹、用途和创建时间。快照不可变；指纹由当前属性规则内容计算，不是运行时版本号。

`derived_stats`保存完整普通属性，包括气血、灵力、先手、攻击、身法、回复与战斗比例属性。
`combat_stats`由同份派生值映射，只将`max_mp`改名为战斗使用的`max_mana`。
战斗、竞技、观战和秘境必须读取完整冻结属性，不得在缺字段时重算基础公式或读取当前内容补齐。

数据库`max_hp`、`max_mp`、`initiative`、`carry_capacity`与`exploration_efficiency_bp`
是已经获得的永久增量，默认零。基础公式与它们相加一次；不取最大值，不因角色已有某境界
而补发历史突破收益。当前气血和灵力属于战斗会话，不写回这些永久增量字段。

## 来源

来源键包括境界、基础属性、道途、功法、装备、辅修、地点、阵法、临时状态。每个来源保存加成值和所属乘区。

当前已消费来源为境界、六项资质、永久增量、已装备实例、功法和体质；道途只保留身份，
尚无明确合同的道途、环境或临时效果不自动生成。装备来源保存实例效果、词条、耐久与淬炼；
功法保存实际效果合计，体质保存选定时效果。所有数值须为非布尔整数，缺来源、缺必要字段、
非法属性或损坏JSON均拒绝；不为旧格式增加默认值。
