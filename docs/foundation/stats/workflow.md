# 属性域：计算生命周期

```text
dirty -> building -> ready
                  \-> invalid
ready -> invalid
```

境界、道途、装备、状态或规则变化时重新构建。`building`只在内存中构建；校验通过得到
不可变`ready`快照；引用缺失、数值越界或内容不可用则进入`invalid`，禁止用于资产结算。

1. 读取现行`stats.formula`与境界内容，校验六项资质，计算基础属性。
2. 加上角色已经获得的永久增量，保留独立来源。
3. 已穿戴装备的词条、效果与武器淬炼按耐久比例衰减并取整，再累计到对应属性。
4. 功法和体质同属构筑乘区，同属性百分比先相加，只乘一次并取整。功法反伤为直接比例值，
   与装备反伤相加，不在战斗回合中再次追加。
5. 按当前内容规定的永久效率与战斗比例上限截断，记录截断原因，生成完整普通战斗映射。

加成类别保留基础、道途、构筑、环境、临时，但没有定义或没有消费入口的效果不凭空应用。
规则参数来自内容，运行时只执行整数算法，不采用浮点权威结果。

预览和即时观战只读，不创建属性、战斗或图鉴记录。正式冻结与业务会话创建在各自事务中
保存完整值与来源，operation先重放，再读取当前构筑。探索及远古洞天、虚空遗迹、时序堡垒开始后，
后续遭遇只取入场冻结属性；改装备、功法、体质或内容不得改变已开始会话。其他秘境沿用每场战斗
开局冻结，不把本条记为整趟秘境入场冻结。正式PvE/PvP仍按原事务结算状态与奖励。

竞技和只读观战统一完整数值输入，但既有基本招式回合仅使用气血、攻击、先手与身法；完整快照
不等同于其他比例属性、神通和灵力消耗已经参与这些回合。

天劫和终局保留显式的高阶场景尺度与装备倍率，体质通过共享纯规则作用于该场景最终值。
它们不是普通面板公式的另一条隐式回退路径，也不因普通属性统一而改变敌人、奖励或开放条件。
