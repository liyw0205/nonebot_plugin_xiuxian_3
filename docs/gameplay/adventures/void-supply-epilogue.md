# 虚空补给回响

## 范围

`story.mainline.void_archive` 归乡终关完成后，开放一条不改变原虚空档案三段路线的可选后记：

1. `void_archive.supply.1`：从虚空门户沿公开区域边抵达 `void.first_route`，必须以本关开始后的已结算移动完成。
2. `void_archive.supply.2`：本关开始后安排并完整领取 `idle.void_supply_watch`。路线要求炼虚一层、每日一次、十二小时；逾时保底、取消、旧安排和仍在运行的安排均不算。
3. `void_archive.supply.3`：本关开始后在 `explore.void_route`、`void.first_route` 的探索结算中取得 `item.void_anchor`。只认服务端结算结果，不认开始前库存、其他地点、他人结果或测试注入。

## 既有规则边界

后记复用现有移动、闲居、探索、奖励池、快照、事务和 operation 幂等实现，不新增成本、次数、权重或经济规则。第一航道、补给看守及锚点奖励池必须保持 `open`/`active` 且可由内容加载器解析；不得借此开放 `void.sect_fortress` 或 `void.void_market`。

主线开始时冻结正文、目标、奖励和开始时间。目标不足时领取保持进行中并零写；达到目标后奖励写入与主线状态在同一事务中完成，失败可重试，原 operation 重放只返回原结果。

## 玩家路径

完成 `void_archive.return.8` 后查看虚空档案主线，按关卡行动：`前往 虚空第一航道`、`挂机预览/开始挂机 虚空补给看守`、`开始探索 虚空航道历练`。帮助页说明炼虚一层、完整十二小时窗口和锚点必须来自真实探索结算；不把 locked 地点或未来内容描述为可用。

## 验收

专项测试覆盖严格引用（地点、模式、物品、完整/保底奖池）、公开移动、完整闲居领取、真实探索锚点、旧/逾时/部分闲居拒绝、目标不足零写、快照热更/重启、事务回滚和 operation 重放。种子迁移登记主线文件旧/新 SHA-256 及数据提交 `cb25be1` 的 Git provenance，并保留历史与自定义文件。
