# 核心：战斗域

战斗域属于多人游戏的正式玩法，负责自动回合训练战、单人/多人 PVE、精英、PvP、行动序列、状态效果、
回放和战斗奖励待领取。PvE 与 PvP 共用服务端战斗引擎；战斗进行中不提供手动攻击、防御、
选技能或选目标指令。

战斗运行时按前置能力分批开放。当前已有训练傀儡、少量高阶任务具名遭遇和天劫三阶段试炼的
单人自动 PVE 会话；这些遭遇校验境界和敌人定义地点，并保存开始快照与回放。天劫试炼已完成
三阶段属性、技能、债务护盾、回放和重启后结算验收。探索遭遇、多人 PVE、终局最终战和 PvP
仍未开放。

当前境界域仅开放 `终局战预览`/`预览终局战` 的只读前置检查，用于核对终局战资格；
它不创建终局战斗会话、不锁定飞升凭证，也不代表终局自动回合战斗运行时已开放。
