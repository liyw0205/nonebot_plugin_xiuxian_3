# 核心：战斗域

战斗域属于多人游戏的正式玩法，负责自动回合训练战、单人/多人 PVE、精英、PvP、行动序列、状态效果、
回放和战斗奖励待领取。PvE 与 PvP 共用服务端战斗引擎；战斗进行中不提供手动攻击、防御、
选技能或选目标指令。

战斗运行时按前置能力分批开放。当前已有训练傀儡、少量高阶任务具名遭遇、探索木鼠/雾隐守卫
和天劫三阶段试炼的单人自动 PVE 会话；v0.3 活动窗口内的 `开始魔界战` 使用固定
`enemy.demon_war_front`，结算结果可由事件域核验战斗贡献；这些遭遇校验境界和敌人定义地点，并保存开始快照与
回放。探索结算会自动创建并推进关联战斗，胜负后才发放冻结奖励。双人队伍 PVE 使用独立的
队伍战斗表、全体成员快照、资产锁和每成员唯一奖励，不扩展单人会话。2v2/3v3/2v3 PvP 使用独立竞技场队伍快照和行动表，不复用队伍 PVE 会话。天劫试炼已完成三阶段属性、
技能、债务护盾、回放和重启后结算验收。终局最终战已开放 1 名发起者加最多 4 名协助者，
使用独立会话/成员/行动/奖励表；四人以上普通 PVE 和跨服 PvP 仍未开放。

`终局战预览`/`预览终局战` 是只读资格检查。`创建终局战`托管发起者的飞升凭证，
协助者使用 `加入终局战 <battle_id>`；发起者使用 `开始终局战` 推进自动回合，守界人半血时
必须用 `选择终局战 继续|留界` 作不可逆选择。崩溃后可用 `恢复终局战` 继续，成员可用
`终局战回放`读取历史。胜利消耗凭证并进入 `ascension_ready`；失败增加 25 天劫债、冷却
7 天并返还凭证，取消/大厅过期也返还。
