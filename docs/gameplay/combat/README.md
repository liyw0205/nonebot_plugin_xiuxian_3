# 核心：战斗域

战斗域属于多人游戏的正式玩法，负责自动回合训练战、单人/多人 PVE、精英、PvP、行动序列、状态效果、
回放和战斗奖励待领取。PvE 与 PvP 共用服务端战斗引擎；战斗进行中不提供手动攻击、防御、
选技能或选目标指令。

战斗运行时必须后置：角色、属性/资源、装备、技能、队伍、持久化事务和回放基础完成并
通过验收前，本目录只维护规则、内容快照、接口合同和测试夹具，不实现战斗循环。

当前境界域仅开放 `终局战预览`/`预览终局战` 的只读前置检查，用于核对终局战资格；
它不创建战斗会话、不锁定飞升凭证，也不代表自动回合战斗运行时已开放。

行动选择或结算结果；服务端根据开始时快照和自动行动策略生成完整回放。
