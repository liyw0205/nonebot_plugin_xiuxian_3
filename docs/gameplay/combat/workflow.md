# 战斗域：行动与状态

```text
created -> running -> won/lost/escaped/expired -> settled
```

自动回合顺序：服务端根据快照和策略选择行动 -> 目标合法性 -> 消耗预览 -> 命中/抵抗
-> 主效果 -> 状态效果 -> 持续效果 -> 胜负判断。客户端不参与回合选择。

状态分为增益、减益、持续、控制和道途状态。每个状态定义叠加、刷新、覆盖、免疫、
驱散和结束条件。行动超时按战斗定义自动防御、跳过、判负或结束；断线不会暂停自动战斗。

## 天劫三阶段

`enemy.tribulation_heaven` 按敌方气血万分比自动选择阶段：`>=6667 bp` 为雷劫、
`3334..6666 bp` 为心劫、`0..3333 bp` 为道劫。阶段切换在行动前计算，玩家攻击使用
阶段伤害修正 `10000/9500/9000 bp`，敌方攻击使用 `5500/8000/12000` 和命中加成
`0/200/400 bp`。天劫债每 10 点向玩家伤害追加 `200 bp` 护盾，最多 `2000 bp`；债务、
阶段、技能和实际伤害都写入行动回放。

天劫开始时冻结高阶属性、装备词条、地点、敌人配置、随机池和规则版本。进程中断或重启后，
通过 `battle_sessions` 的状态继续读取；同一个 `battle_id + expected_round` 只允许一条行动
operation。战斗必须先结算为胜负，再由 `tribulation.settle_trial` 一次性发放进度、功勋、债务
和保护阵返还。
