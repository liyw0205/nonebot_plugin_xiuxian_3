# 核心：灵兽与灵骑域

宠物按修仙3改称灵兽，坐骑按修仙3改称灵骑。两者都是有独立成长的实体，不是普通堆叠物品。

当前状态为 `locked`：灵兽、灵骑、灵具和鞍具只有内容定义与测试夹具，尚未创建运行时实体或
战斗辅助入口。待实体成长、休养和 `BattleSnapshot` 合同验收后再开放，详见[当前开发状态](../../current-status.md)。

## 实体与边界

`BeastInstance`：实体 ID、品种、稀有度、等级、经验、亲和、技能槽、进化阶段、装备槽、绑定、状态与版本。

`MountInstance`：实体 ID、品种、等级、经验、耐力、速度档、鞍具槽、绑定、状态与版本。

灵兽/灵骑可提供探索路线、负重、运输、战斗辅助或生活效率的有限 modifier；不得替代玩家境界、道途、主战技能或飞升资格。战斗辅助必须进入 BattleSnapshot，不能实时改写战斗。

## 共同规则

- 每角色首版最多 3 个灵兽、1 个灵骑；出战/出行槽分别 1 个。
- 灵兽升级消耗灵粮/训练记录；蜕变必须消耗品种专属材料并满足亲和/等级，失败不降阶。
- 灵兽灵具和灵骑鞍具是唯一实例，使用物品锁、耐久、强化/洗练规则，但不与玩家法器槽混用。
- 释放/放生保留历史记录；绑定实体不能交易，未绑定蛋/契约必须明确定义交易窗口。
