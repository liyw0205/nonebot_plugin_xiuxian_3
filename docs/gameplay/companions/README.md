# 核心：灵兽与灵骑域

宠物按修仙3改称灵兽，坐骑按修仙3改称灵骑。两者都是有独立成长的实体，不是普通堆叠物品。

当前状态为 `open`：已接入运行时实体、结缘、状态查询、灵粮喂养、灵具绑定、休养、木鼠首阶蜕变、探索/战斗开始快照和灵骑运输。木鼠、铁背鼠的探索发现率在探索开始时冻结，只提高内容明确启用 `item_weight_bonus` 的含物品结果权重；不改变声望、资源或无收获结果。运输会冻结灵骑、等级、耐力与鞍具效果；抵达结算时增加运输经验，旅途险象按内容包判定受伤并进入休养。

## 实体与边界

`BeastInstance`：实体 ID、品种、稀有度、等级、经验、亲和、技能槽、进化阶段、装备槽、绑定、状态与版本。

`MountInstance`：实体 ID、品种、等级、经验、耐力、速度档、鞍具槽、绑定、状态与版本。

灵兽/灵骑可提供探索路线、负重、运输、战斗辅助或生活效率的有限 modifier；不得替代玩家境界、道途、主战技能或飞升资格。战斗辅助必须进入 BattleSnapshot，不能实时改写战斗。

## 共同规则

- 每角色首版最多 3 个灵兽、1 个灵骑；出战/出行槽分别 1 个。
- 灵兽升级消耗灵粮/训练记录；蜕变必须消耗品种专属材料并满足亲和/等级，失败不降阶。
- 灵兽灵具和灵骑鞍具是唯一实例，使用物品锁、耐久、强化/洗练规则，但不与玩家法器槽混用。
- 释放/放生保留历史记录；绑定实体不能交易，未绑定蛋/契约必须明确定义交易窗口。

## 相伴与御兽（v0.7）

`灵兽相伴` 每日一次提升灵兽亲和（基础 3，御兽体质每点 +1），补上了此前 `affinity`
只能被蜕变读取、却无法增长的缺口；`constitution.beast_affinity` 同步由锁定改为可选。
数值与校验见 [content-v0.7.md](content-v0.7.md)。

## 战技与普通 PvE（v0.8）

蜕变开启灵窍后，灵兽可从适配自身物种、蜕变来源和已开启槽位的战技中选择装配。
`灵兽战技 <编号>` 只读查看当前装配、开放灵窍和可用选项；使用
`装配灵兽战技 <编号> <灵窍> <战技名或键>` 更换槽位，或用
`卸下灵兽战技 <编号> <灵窍>` 清空。操作不消耗资产，事务回执支持重试；灵兽随行、战斗资产锁定、
跨角色实例、关闭内容、不匹配物种或未开启灵窍均不能装配。

当前内容仅有两类一次性效果：踏风先声强化普通探索遭遇中的首次主动攻击，根甲护主/青玉共鸣减轻
首次实际承受的敌方攻击。探索开始与普通 `standard_pve` 队伍开战时冻结己方灵兽的战技键与完整效果；
成员只使用自己的出战灵兽。回合事件进入现有 action/state 回放，后续内容变化或卸下不会改写已开战记录。
专属秘境、PvP、竞技和其他战斗模式不触发灵兽战技。

完整内容合同与验收见 [content-v0.8.md](content-v0.8.md)。
