# v0.2 灵兽与灵骑内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.2`，`rule_version=companions-0.2.0`。

- `beast.evolution.wood_rat_1`：灵兽等级 10、亲和 40、灵果 3、灵石 300；100% 蜕变为 `beast.iron_rat`，开启 1 技能槽；每角色每品种一次。
- `mount.evolution.bamboo_deer_1`：灵骑等级 5、云布 2、灵石 500；100% 变为 `mount.cloud_deer`，耐力 30、运输耗时 -5%。
- `beast.gear.cloud_pouch`：负重 +10、耐久 1500；`mount.tack.cloud_saddle`：云舟移动耗时 -5%、耐力 +10。
- 灵兽等级上限 20，灵骑等级上限 10；每角色仍只可出战/出行 1 个。

蜕变失败只在内容明确的高阶扩展出现；本版本材料预检查失败零扣除，重复领取不重复生成实体或灵具。
