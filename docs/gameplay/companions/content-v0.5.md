# v0.5 灵兽与灵骑内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.5`，`rule_version=companions-0.5.0`。

- `beast.evolution.void`：等级 40、亲和 85、普通航道材料 3；成功率 70%，失败休养 12h；等级上限 50。
- `mount.evolution.void`：灵骑等级 30、航道鞍具 1；成功率 70%；航行耗时 -12%、耐力 80。
- `beast.gear.void_pack`：补给负重 +20；`mount.tack.void_harness`：航道维护成本 -5%；均不可用于终局战属性。

虚空不稳定、抗性和航线在会话创建时冻结；蜕变失败不增加天劫债，不产生虚空突破资源，不永久损毁实体。
