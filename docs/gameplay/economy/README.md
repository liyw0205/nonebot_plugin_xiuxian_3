# 核心：经济域

经济域负责钱包、灵石流水、市场订单、摆摊、委托、手续费、锁定资产和经济观测。

钱包、物品流水和 operation ledger 已作为基础设施被现有用例使用；固定摆摊、生产委托和 v0.3
`trade.xuantian_to_demon` 和 `trade.xuantian_to_beast` 固定跨界贸易已开放：前者只允许在魔渊集市执行，后者只允许在万兽山执行，均按 UTC 周一重置每周次数；魔核/妖血保留 24 小时角色绑定，活跃绑定数量不会进入摆摊可用库存。`trade.three_realms` 已开放于三界贸易口，消耗魔核 2、妖血 2 兑换绑定神魂晶 1，每角色每周 3 次，并要求魔界/妖界声望均达到 200。
限量拍卖已开放每周 20 槽位的发布、竞价和结算/流拍恢复；复杂市场玩法、批量委托和跨服交易仍未开放。任何新增资产流转必须先补齐锁定、过期、并发和恢复合同，
再更新[当前开发状态](../../current-status.md)。
