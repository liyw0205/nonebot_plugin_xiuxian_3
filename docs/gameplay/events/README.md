# 核心：活动与世界事件

活动域负责由已结算领域 operation 投影出的任务进度、固定轮次和活动奖励。

当前运行时开放 `event.spirit_spring`：每周三、周日 20:00 UTC 在灵泉谷创建 30 分钟轮次，
灵泉采集结算按原探索 operation 去重计入灵叶贡献；全服累计 100 份后，达到个人 10 份门槛的
角色可在结束后 24 小时内领取奖励。重复贡献、重复领奖和过期轮次均由数据库唯一约束与
operation ledger 保护。

任务、排行、复杂世界事件和战斗事件仍按[当前开发状态](../../current-status.md)逐步开放；
`content-v*.md` 是规则合同，不代表所有入口已接入。
