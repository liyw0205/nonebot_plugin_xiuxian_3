# 核心：活动与世界事件

活动域负责由已结算领域 operation 投影出的任务进度、固定轮次和活动奖励。

`引路簿` 展示寻仙、入道、近郊采集和首次生产四项常驻引路任务；`领取引路嘉奖 <任务名>`
只认本人已落账的寻仙/入道 operation、成功近郊采集结算或成功生产结算。任务名、触发条件和奖励
分别取自任务与奖励内容；来源证据、领取记录、资产变更和 operation 快照同事务提交。切磋与训练
傀儡观战不产生任务进度或嘉奖。

`每日修行` 按 UTC 日为每名角色冻结七项修行，从已结算的本人操作中逐项记进；完成任意三项后，
可在次日结束前通过 `领取日课嘉奖` 领取灵石、精力和青石镇名望。轮次同时冻结青石镇名望上限，
嘉奖记录与回复按上限计算实际所得。修行榜只查阅，不接受自行提交的
来源或进度；上一日的任务不会并入新一日。

当前运行时开放灵泉事件。轮次时段、持续时间、贡献来源、每份贡献值、个人上限、全服目标、
领取门槛和领奖窗口均由 `data/事件/事件.json` 提供；灵泉采集结算只在活动窗口内按原探索
operation 去重计入对应来源。创建轮次时会冻结完整事件内容、奖励和展示名称，之后内容调整、关闭
或重启都不改变该轮次的结算；没有对应来源物品的探索不会创建轮次。重复贡献、重复领奖和过期
轮次均由数据库唯一约束与 operation ledger 保护。

魔界入侵、妖界贸易与界隙裂痕的轮次、全服目标、贡献来源与数量、个人领取门槛和嘉奖引用均从
`data/事件/事件.json`、`data/奖励/奖励.json` 读取。创建轮次时冻结完整配置和奖励；此后即使内容变化或
运行时重启，来源核验、结算与领奖仍使用该轮次的冻结规则。内容包解析会校验地点、境界、物品、声望资源，
并要求贸易键出现在地点开放动作中；队伍类型列表也必须是非空且无重复的字符串列表。三类事件共享奖励结算，
将物品、灵石、角色数值和阵营声望一次提交。

领域前线已由独立 rules/models/repository/use-cases/migration 模块开放：UTC 4 小时活动窗口切成 30 分钟轮次，
支持化神/宗门/领域裂痕门槛、每宗门 20 人参战快照、服务端领域战与占点来源、个人贡献领奖和 21 日领域战赛季匿名冻结榜。
`开始领域战` 使用共享自动战斗结算；只有与本轮和本人绑定的正式领域战胜利可以记入战斗功绩，战败按正式战斗规则结算，
同地点的其他战斗不能作为来源。战斗行动与结算可在重启后沿原会话恢复。
`领域前线`、`加入领域前线`、`开始领域战`、`占点领域前线`、`贡献领域前线`、`领取领域前线奖励`、
`领域赛季`、`领取领域赛季奖励` 与 `兑换领域核心 <赛季编号>` 已接入 QQ 官方和 OneBot V11。

化神/炼虚许可任务已开放最小玩家闭环：`完成领域委托`、`完成远古洞天任务`、`开始跨界战`、
`开始界壁试炼`、`探索档案遗迹`、`交付虚空档案` 和对应许可领取命令均进入统一 application，
任务组件由 `quest_progress` / `quest_events` 审计。v0.3 `quest.demon_main_1` 已接入服务端探索证据核验：魔界声望达到 200 且有两次已结算的 `explore.demon_abyss` 胜利后，`领取魔界主线` 原子写入任务事件、版本快照和 `access.demon.fallen_ruins`。`event.demon_invasion` 通过 `魔界入侵` 查看轮次，`贡献魔界战场 战斗|运输|维修` 只投影已结算的服务端 operation，个人贡献达到 50 后以 `领取魔界入侵奖励` 领取世界功勋 50 和魔界声望 20；操作和领奖均幂等。`维护设施` 由玩家按服务端业务日维护个人槽位，真实维护 operation 可作为维修贡献来源；`开始魔界战` 在活动窗口内创建固定敌人自动战，结算后可投影战斗来源。运输/维修/战斗来源与领奖是当前最小玩家路径。`event.beast_trade` 和 `event.boundary_rift` 已补齐固定轮次、来源 operation 投影、恢复和双适配器领奖；完整虚空档案副本、其他复杂世界事件和
虚空档案副本、`enemy.archive_keeper` 自动战、三项档案碎片周任务和 `event.archive_unlock` 已接入；其他多人战斗仍按[当前开发状态](../../current-status.md)逐步开放。三界赛季由独立 season repository
提供 28 日 UTC 窗口、阵营功勋/多人副本/宗门三榜、匿名冻结快照、前 100 名奖励和 7 日领奖窗口；
`三界赛季` 与 `领取三界赛季奖励` 已接入 QQ 官方和 OneBot V11。绑定神魂晶由赛季绑定审计表记录，
摆摊、拍卖和求购会统一排除。终局赛季三榜由独立 season repository
接入：结局榜读取正式结局，协作榜仅读取成功多人终局战；到期按需冻结匿名快照，称号领取幂等，
逾期补发展示称号但不自动确认篇章资格。`event.heart_demon_trial` 由元婴突破失败在同一事务写入独立 `heart_demon_event_projections`，记录事件、突破结算 operation、版本快照和 24 小时截止时间；`心魔事件` 只读查询会先处理到期事件，按 `heart_demon.face` 自动结算。`化解心魔` 回写事件投影；已结算事件再次选择返回 `HEART_DEMON_ALREADY_RESOLVED`，不进入公共排行。`content-v*.md` 是规则合同，不代表所有后续入口已接入。

虚空前线赛季由独立 `void_frontier` 模块接入：`虚空前线` 查询/冻结 28 日匿名玩家与宗门榜，
`领取虚空前线周任务` 领取每周最多 5 次的待领取箱，`领取虚空前线奖励 <赛季编号>` 领取前 100 名赛季奖励。
赛季分数由航道、风暴救援、跨服胜利和自然结束联盟合同来源实时投影；前 3 宗门写入 7 日虚空集市优先权。
QQ 官方与 OneBot V11 共用 application、迁移、operation ledger 和冻结快照。
