# 核心：探索域

探索域负责采集、历练、探索随机事件以及探索会话；悬赏、秘境和遗府的专属用例分别由
`gameplay/adventures/` 复用本域会话合同。

当前代码已开放 v0.1 的近郊采集、近郊短历练、灵泉采集和雾隐洞天探索，并接入 v0.2 的云铁矿区
采集、矿兽遭遇、云舟试炼和洞天二层探索/精英遭遇；云铁矿区和洞天二层分别要求矿区许可标记和已抵达二层，云舟试炼要求金丹 L1 且位于云舟渡口。云舟试炼会冻结奖励种子，风暴按服务端 roll 提供等待、支付或返航选择，QQ 官方和 OneBot V11 均复用同一 application 用例。悬赏中的草药补给
和生产订单由冒险域运行时接入；训练傀儡悬赏、秘境和遗府仍是锁定内容。达到遭遇概率后，
探索会冻结开始时的属性、装备、地点和奖励种子，创建关联的自动回合单人 PVE 会话；战斗
胜负和行动回放完成后才结算探索奖励，失败不发放冻结奖励。旧会话仍兼容 `combat_pending`
恢复路径。

战斗由 `../combat/` 结算；奖励由基础物品/资源域结算。探索遭遇支持单人会话，已确认的双人队伍可在支持地点创建独立队伍 PVE；三人以上探索战斗仍未开放。秘境/遗府仍未开放；阵堂迷雾屏障生产由生产域独立结算。
