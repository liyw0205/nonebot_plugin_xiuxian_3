# 核心：探索域

探索域负责采集、历练、探索随机事件以及探索会话；悬赏、秘境和遗府的专属用例分别由
`gameplay/adventures/` 复用本域会话合同。

当前代码已开放 v0.1 的近郊采集、近郊短历练、灵泉采集和雾隐洞天探索。悬赏中的草药补给
和生产订单由冒险域运行时接入；训练傀儡悬赏、秘境和遗府仍是锁定内容。探索遭遇战只记录
为 `combat_pending`，自动回合 PVE/PvP 战斗运行时按[当前开发状态](../../current-status.md)
后置，不在本域提前实现。
