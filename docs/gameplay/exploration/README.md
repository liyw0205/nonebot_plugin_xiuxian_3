# 核心：探索域

探索域负责采集、历练、探索随机事件以及探索会话；悬赏、秘境和遗府的专属用例分别由
`gameplay/adventures/` 复用本域会话合同。

当前代码已开放 v0.1 的近郊采集、近郊短历练、灵泉采集和雾隐洞天探索，并接入 v0.2 的云铁矿区
采集、矿兽遭遇、云舟试炼和洞天二层探索/精英遭遇；云铁矿区和洞天二层分别要求矿区许可标记和已抵达二层，云舟试炼要求金丹 L1 且位于云舟渡口。云舟试炼会冻结奖励种子，风暴按服务端 roll 提供等待、支付或返航选择，QQ 官方和 OneBot V11 均复用同一 application 用例。v0.3 另接入魔界堕落遗迹和万兽山单人探索切片：元婴 L1、每日 2 次，地点、阵营、污染/血脉稳定、跨界惩罚和奖励池均按开始快照结算；魔渊奖励为魔核/魔界声望/`item.clue.demon_contract`/心魔事件，万兽山奖励为妖血/妖界声望/`item.clue.beast_bloodline`/祖灵事件，两个线索都只作为绑定展示物，未开放分支不伪造资产。两次已结算胜利和魔界声望 200 可通过 `领取魔界主线` 领取 `quest.demon_main_1`，服务端写入证据事件、进度、版本快照和遗迹权限。正式魔界事件、完整核心区、心魔独立事件和跨界多人副本仍未开放。悬赏中的草药补给
和生产订单由冒险域运行时接入；`event.demon_invasion` 已开放轮次、运输/个人设施维护/战斗来源投影和领奖，维修来源可由 `维护设施` 玩家命令产生；`xuantian.war_front` 可在活动窗口内通过 `开始魔界战` 创建固定自动战；训练傀儡悬赏、秘境和遗府仍是锁定内容。达到遭遇概率后，
探索会冻结开始时的属性、装备、地点和奖励种子，创建关联的自动回合单人 PVE 会话；战斗
胜负和行动回放完成后才结算探索奖励，失败不发放冻结奖励。旧会话仍兼容 `combat_pending`
恢复路径。
