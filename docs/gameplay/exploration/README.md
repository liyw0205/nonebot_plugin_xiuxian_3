# 核心：探索域

探索域负责采集、历练、探索随机事件以及探索会话；悬赏、秘境和遗府的专属用例分别由
`gameplay/adventures/` 复用本域会话合同。

当前代码已开放 v0.1 的近郊采集、近郊短历练、灵泉采集和雾隐洞天探索，并接入 v0.2 的云铁矿区
采集、矿兽遭遇、云舟试炼和洞天二层探索/精英遭遇；云铁矿区和洞天二层分别要求矿区许可标记和已抵达二层，云舟试炼要求金丹 L1 且位于云舟渡口。云舟试炼会冻结奖励种子，风暴按服务端 roll 提供等待、支付或返航选择，QQ 官方和 OneBot V11 均复用同一 application 用例。魔界堕落遗迹、万兽山单人探索要求元婴 L1、每日 2 次；地点、阵营、污染/血脉稳定和跨界惩罚按开始快照处理。万兽山奖励读取 `reward_pool.exploration.beast_hunt`，开始时冻结奖池键与实际结果；兽血、妖界声望、绑定血脉线索与明确的无收获分支仍按原权重结算，福缘只提高物品结果的权重。魔界堕落遗迹奖励与祖灵湖奖励仍待迁入内容奖池。两个线索都只作为绑定展示物，未开放分支不伪造资产。两次已结算胜利和魔界声望 200 可通过 `领取魔界主线` 领取 `quest.demon_main_1`，服务端写入证据事件、进度、业务快照和遗迹权限。完整核心区和其他跨界多人副本仍未开放；`event.demon_invasion`、`event.beast_trade`、`event.boundary_rift` 已开放轮次、来源 operation 投影、恢复和领奖，`cave.boundary_realm` 界隙多人副本已开放 2–5 人确认队伍。悬赏中的草药补给
和生产订单由冒险域运行时接入；`event.demon_invasion` 已开放轮次、运输/个人设施维护/战斗来源投影和领奖，维修来源可由 `维护设施` 玩家命令产生；`xuantian.war_front` 可在活动窗口内通过 `开始魔界战` 创建固定自动战；其他单人秘境和遗府仍是锁定内容，首条 `instance.legacy.demon_reliquary` 由冒险域独立运行。秘境试炼由冒险域独立保存节点和资源锁，也不属于探索会话。达到遭遇概率后，
探索会冻结开始时的属性、装备、地点和奖励种子，创建关联的自动回合单人 PVE 会话；战斗
胜负和行动回放完成后才结算探索奖励，失败不发放冻结奖励。`combat_pending` 会话可在进程重启后继续结算。

魔渊堕落遗迹和万兽山现支持 2–5 人跨适配器确认队伍：分别使用 `创建魔渊队伍`、`创建万兽队伍`，开始时冻结准入条件并原子扣除每人 20 体力；战斗仍由 combat 域的队伍会话结算。其他跨界多人副本保持关闭。
