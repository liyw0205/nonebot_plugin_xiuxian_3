# 核心：探索域

探索域负责采集、历练、探索事件和探索会话；悬赏、秘境和遗府由冒险域使用对应的独立状态机。
各模式在开始时冻结准入、奖励与战斗所需参数，由服务端完成结算。玩家当前可用的地点、活动和队伍
入口见[当前可用能力](../../availability.md)。
