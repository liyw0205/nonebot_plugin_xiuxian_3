# 核心：常驻经营域

常驻经营域提供不依赖境界提升的长期循环：居所/洞府、灵田、城镇委托、服务订单、商贸运输、地方名望与公共建设。它从 `mortal` 开始开放；境界只能扩展效率、风险和高阶地区，不能作为基础生计的唯一前置。

当前已开放：止血草与灵叶灵田、城镇委托、服务订单、短途运输、地方公共项目，以及 v0.3 魔界/妖界贸易许可。`申请贸易许可 魔界|妖界` 校验对应三界引导、阵营声望 80 并扣 500 灵石，许可有效 7 天，为对应跨界派遣和妖界栖地悬赏提供准入。公共项目按周轮换，贡献上限为单次 30 点，完成后按快照在 7 天内生效；个人累计贡献达到 10 点后可结算一次奖励。v0.4 的 `project.domain_refuge`、`project.abyss_purification`、`project.ancestral_habitat` 已按权限按需物化并开放材料贡献，每人每项目每日最多 30 点；运输、净化、灵兽驯养与修复可引用本人已成功结算的来源凭证，每份凭证只能贡献一次，服务端按来源事务固定贡献点数。灵叶需要小院，播种快照固定 `livelihood.harvest` 阵砂副产物结果；灵泉事件中的灵叶贡献另见[活动域](../events/README.md)。

公共项目的名称、说明、需求、贡献资源、成效、奖励、名望地点、权限和运输/净化/驯养/修复来源均登记在 `data/生活/生活.json`；项目物化后冻结这些内容，领奖复用角色奖励事务，内容改动不影响已存在项目。玩家回复只显示中文名称、物资、成效和进境，不展示稳定键或内部状态。

公共项目达标并成功结算后，会按项目快照收入对应的道统服务图鉴见闻；图鉴写入与项目奖励、名望和 operation 同事务提交，写入失败会整体回滚并可用原 operation 重试。训练傀儡与切磋只是观战，不会贡献项目、发放奖励或写入图鉴。

城镇委托的业务日快照冻结材料、报酬、名望键和地点上限；交付复用共享角色状态事务，回复只显示实际所得。已接取委托和历史 operation 不依赖当前奖励重新校验，新接取仍遵守开放规则；QQ 官方与 OneBot V11 共用应用用例、仓储和幂等结果。

仓储按领域拆分：居所事务在 `repository.py`，灵田事务在 `field_repository.py`，委托、服务、运输、公共项目与贸易许可分别在各自的 repository mixin 中。

短途运输规则由生活内容提供，出发冻结报酬、名望地点与上限、货物及名称、延误及灵骑快照；抵达后

关闭不阻断已出发运输或历史重放，回复只显示实际所得，不扣回超过旧上限的已有名望。

所有 `content-v*.md` 遵守 [版本内容开发合同](../../content-development-contract.md)。常驻经营的产出只允许材料、灵石、名望、信誉、建设与服务资格；不得直接发放修为、跨境突破材料或战斗属性。
