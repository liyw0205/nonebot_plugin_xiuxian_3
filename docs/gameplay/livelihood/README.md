# 核心：常驻经营域

常驻经营域提供不依赖境界提升的长期循环：居所/洞府、灵田、城镇委托、服务订单、商贸运输、地方名望与公共建设。它从 `mortal` 开始开放；境界只能扩展效率、风险和高版本地区，不能作为基础生计的唯一前置。
