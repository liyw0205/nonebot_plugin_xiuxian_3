# v0.11 山路行商事件

本版在既有短途运输上开放一条可公开抵达的铁木林商路，并为三条路线登记沿途事件。旧路线
保留原有固定收益；事件叙事和结果在开始运输时按 `operation_id` 确定性冻结，结算不重新抽取。

## 玩家路径

玩家在青石镇或其他路线起点用 `运输预览` 查看货值、体力、次数与沿途可能，使用真实背包货物
`开始运输`。进行中可用 `运输状态` 查看事件预告和抵达时间，抵达后用 `结算运输`。铁木林商路
要求寻道阶段，接受木材、铁石或阵砂，所得可直接进入既有生产和公共项目来源链。

## 内容合同

每条 `route` 记录可声明 `events` 数组；事件字段为 `key`、`name`、`desc`、`weight`、
`outcome`（`success`、`partial`、`failed`）、`reward_multiplier_bp`、`reward_bonus_stones`、
`reputation_bonus`、`cargo_return_bp` 和 `item_rewards`。解析器拒绝空池、重复 key、无效权重、
超出万分比范围及关闭/未知物品。`event_mode=dynamic` 才启用收益差异；未声明的历史路线使用
兼容模式，保持既有收益。

铁木林商路 `route.town_ironwood_grove` 的成功事件给予额外灵石、青石镇名望和阵砂；部分事件
按半价结算；失败事件不发报酬并退回锁定货物。所有物品必须在公开 `item` 内容中存在，不能
由测试直接注入背包替代来源。活动、支付、跨服和未来锁定效果不在本版开放。

## 恢复边界

开始事务同时锁定货物、体力、延误和事件快照；重启、内容改名/关闭及旧运输快照仍可按原结果
结算。奖励、退货、名望、灵骑和 operation 写入同一事务，失败完整回滚；相同请求只回放原
operation，其他输入返回具体冲突。回复隐藏稳定 key 与 operation 编号，真实异常保留上下文。
