# v0.9 常驻经营内容基线：居所物资箱

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.9`，
`rule_version=livelihood-0.9.0`。本版只把 v0.1/v0.7 已冻结的居所物资箱容量接入运行时：让
`capacity.storage_slots` 真正生效，并开放存入、取回与查看。不改居所租住、灵田、休整、生产、
旅行、战斗与经济的既有语义，也不新增物品、配方、地点或奖池。

## 1. 物资箱容量

| 居所 | 格数 |
|:--|--:|
| `residence.town_room` | 10 |
| `residence.courtyard` | 20 |
| `residence.herb_court` | 24 |

容量登记在 `data/生活/生活.json` 的居所 `capacity.storage_slots`，租住时写入居所快照并按快照
计算；旧租约快照缺少该字段时按当前居所定义回退，没有可用定义时为 0。一格存放一种物品，
同一物品的数量合并在同一格；格数只按不同物品键计数，不按数量计数。

## 2. 玩家流程

- `存入居所 止血草 4`：从行囊扣除 4 份止血草，占用或复用止血草所在的一格。
- 再次 `存入居所 止血草 3`：同格合并为 7，不新增格。
- `取回居所 止血草 2`：物资箱该格减为 5，行囊增加 2；取空后释放该格。
- `我的物资箱`：显示已用格数/总格数与每格的中文物品名、数量。
- `我的居所` 同时显示物资箱已用格数与容量。

存入要求当前有生效居所；取回与查看不要求居所仍生效，租约到期后仍可取回已有物资。重新租住
后按新居所的容量继续使用；新居所容量更小时，已有物品仍可逐格取回，但在已用格数降到容量以下
之前不能存入新的物品种类。

## 3. 失败与零写边界

- 没有生效居所时存入返回 `RESIDENCE_REQUIRED`，不扣行囊、不写库存。
- 新物品种类且格数已满返回 `STORAGE_FULL`；取出至少一种物品释放格位后才可继续存入。
- 行囊数量不足返回 `RESOURCE_INSUFFICIENT`。
- 未知物品返回 `ITEM_NOT_FOUND`；数量缺失、为 0、为负或不是整数返回 `INVALID_STORAGE_COMMAND`。
- 物资箱没有该物品返回 `STORAGE_ITEM_NOT_FOUND`；取回数量超过库存返回
  `STORAGE_QUANTITY_INSUFFICIENT`。
- 以上失败均不改变行囊、物资箱或 operation 记录。

## 4. 持久化与幂等

`residence_storage` 以 `(player_id, item_key)` 唯一记录玩家、物品键、数量与时间戳，数量必须
为正。存入与取回都在单一事务内完成 operation 回放检查、居所/格数/行囊校验、资产变更与库存
写入，并记录 operation 结果：

- 同一 operation 重放返回原结果，`idempotent_replay=True`，不重复扣取或发放；
- 不同请求复用 operation 返回 `OPERATION_CONFLICT`；
- 库存行数量损坏或写入故障整笔回滚，可用原 operation 重试；
- 重启后物资箱内容与 operation 回放保持不变。

## 5. 呈现

存入与取回回复显示物品中文名、本次数量、该物品结存与格数；`我的物资箱` 显示格数、每格中文名
与数量，空箱显示“空”；`我的居所` 显示物资箱已用/总格数。玩家文案不展示稳定键、operation、
玩家 ID 或内部状态。

## 6. 验收

- 三处居所按 10/20/24 格生效；旧租约快照可按当前定义回退。
- 存入合并同格、取回释放空格、格数计数正确；满格拒绝新种类且零写，释放后可继续存入。
- 租约到期只阻止存入，取回与查看仍可用；重新租住按新容量继续。
- 未知物品、非法数量、行囊不足、无库存与超量取回全部零写并返回对应错误码。
- 同一 operation 回放幂等，不同请求冲突；重启后库存保持；损坏行拒绝整笔请求且可重试。
