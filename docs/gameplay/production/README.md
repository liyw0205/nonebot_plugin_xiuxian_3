# 核心：生产域

生产域负责采集后的加工、炼丹、炼器、布阵、灵田、生产订单和生活服务。

当前运行时开放炼丹、炼器、布阵各一条个人生产闭环，以及疗伤丹/木纹剑生产委托；材料/精力/
工具耐久、质量快照、失败返还和过期恢复均已接入。批量订单仍按[当前开发状态](../../current-status.md)
保持锁定；不要把 `content-v*.md` 中的完整配方表当成已经开放的命令。
