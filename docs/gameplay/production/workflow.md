# 生产域：订单状态机

```text
draft -> submitted -> accepted -> locked -> processing
                                      |          |
                                      +-> rejected/expired
processing -> completed/failed/cancelled -> delivered -> settled
```

个人生产可以从预览进入 locked；委托生产必须双方确认。锁定后材料、精力和报酬不能被其他操作使用。失败按配方返回低品质产物、副产物、部分退款或赔偿。

职业大师作品沿用个人生产状态机。开始时快照道途、辅修、地点、境界、输入、产出、失败返还和质量检定；结算只读取订单快照。作品配方不能进入委托流程。`recipe.masterwork.support` 在失败时完整返还已生产的三类辅修作品，失败不产生最终支持作品。

## 本地基础来源

| 配方 | 输入 | 灵石 / 精力 | 秒 / 每日上限 | 产出与消费 |
|:--|:--|:--|:--|:--|
| 矿区登记 | 木材 1、铁石 1 | 20 / 2 | 30 / 1 | 许可 1；携带准入或使用后永久登记 |
| 基础矿镐 | 铁石 2、木材 1 | 10 / 3 | 30 / 3 | 基础镐 1；矿区准入 |
| 精制矿镐 | 基础镐 1、铁石 2 | 20 / 4 | 60 / 2 | 精制镐 1；聚气起，仍只作准入 |
| 小型灵兽行囊 | 木材 2、粗糙灵米 1 | 10 / 3 | 45 / 3 | 行囊 1；装备出战灵兽后负重 +5 |
| 竹鹿鞍具 | 木材 3、铁石 2 | 20 / 4 | 60 / 2 | 鞍具 1；运输灵骑体力消耗 -1 |
| 灵米饭 | 粗糙灵米 2 | 0 / 2 | 15 / 10 | 饭 2；烹饪辅修，使用选择恢复体力/精力 |

参数权威来源为 JSON，本表解释所选基础阶梯。新增基础制作从感气起，精制镐从聚气起，
可在后续境界继续制作；材料由近郊采集、寻仙嘉奖和入道合法取得，不依赖矿区产物。
这些制作的基础质量足以成功，不引入新随机系统；失败表仍沿用个人订单的冻结返还机制。
每日上限按 UTC 日期，过期/恢复沿用结束后 24 小时窗口，失败不返灵石或精力。
许可/矿镐绑定且不可交易，不增加矿区产量或工具耐久玩法。许可使用只消耗一次，
永久授予既有三种准入旗标；已登记后重复使用拒绝且不扣许可。原矿区筑基准入、
悬赏筑基四层、目标和冻结奖励保持原合同。

`recipe.void.crystal_refine` 的原输入/数量不变：虚空锚与虚空晶可从本人服务端结算的
界壁试炼取得。能量晶使用恢复虚力 40，按资源上限封顶、300 秒冷却；未开启虚力零扣除。
九类大师作品补齐绑定物品定义，仍由现有生产与合道交付消费，不新增市场交易。
