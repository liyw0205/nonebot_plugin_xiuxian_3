# 核心：道历与运营循环域

本域把签到、补签到、灵木聚财、日/周/月道契、机缘寻宝、问道行卷、道号、功业录、七日入道与兑换密令统一为可审计的核心运营系统，不属于娱乐功能。

## 资产边界

- 道历、灵木、道契和行卷奖励使用业务日/周/月份快照，不能用客户端时间补领。
- 道契的购买/支付由外部 billing adapter 提供凭证；核心只验证签名、商品键、周期和 entitlement，不保存银行卡/支付秘密。
- 机缘寻宝的随机池、保底、消耗和实际结果必须快照；禁止使用未声明的高阶境界/终局资源池。
- 道号和功业默认是展示或资格，不直接提供永久战斗倍率；内容明确的轻量效果也必须进入属性 modifier 上限。
- 兑换密令不允许直接执行 SQL/资产变更；一个密令按 `code_key + player_id` 唯一领取，可撤销但不能回收已合法发放资产。

## 共享字段

`RoutineClaim`：角色、活动键、业务窗口、资格快照、奖励包、状态、领取时间、内容/规则版本、operation ID。

`Entitlement`：角色、商品键、周期、来源凭证摘要、开始/结束、权益状态、撤销原因、版本。

`RewardPoolRoll`：池键、权重/保底版本、消耗、随机种子摘要、实际结果、operation ID。

`HonorRecord`：道号/功业键、触发来源、获得时间、展示状态、历史版本；已获得记录不可删除，只能隐藏展示。
