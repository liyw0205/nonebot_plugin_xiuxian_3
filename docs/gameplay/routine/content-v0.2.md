# v0.2 道历与运营循环内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.2`，`rule_version=routine-0.2.0`。v0.2 扩展金丹前后运营，不改变 v0.1 的道历唯一、补录次数和道契验签规则。

| 系统 | 稳定键/准入 | 参数与结算 |
|:--|:--|:--|
| 灵木 | `ritual.spirit_tree.advanced`：筑基 L4 或城镇名望 200 | 14 日周期；每日浇灌 1 次；收获灵石 160–240、名望 +4；每月最多 2 周期 |
| 机缘寻宝 | `gacha.fate.foundation`：筑基 L1 | 单抽 100 灵石/票，十连 900；保底 20 抽出宝品线索；不出突破丹/终局物 |
| 行卷 | `pass.wayfaring.foundation`：28 日、40 级 | 周任务加入生产/宗门/秘境；付费权益仍只给展示、名望和线索 |
| 功业 | `achievement.foundation_10` | 完成 10 项筑基阶段功业给道号 `title.foundation_helper`、名望 +20 |
| 道契 | `dao_contract.weekly`/`monthly` v0.2 | 日权益上调为灵石 45/60、精力 4/5；必须版本化，不追溯补发 |
| 七日入道 | `quest.seven_day.v0.2` | 对已完成 v0.1 的角色转为 7 日筑基准备目标；新角色仍先走 v0.1 |
| 密令 | `code.foundation.repair` | 总库存 500；奖励材料/修理券；不可兑换灵石或修为 |

补录每月仍最多 2 次；连续问安达 14 日给名望 +10，不恢复漏签前连续数。版本关闭不删除已获道号/功业记录。
