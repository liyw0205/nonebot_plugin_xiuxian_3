# v0.5 道历与运营循环内容基线

本文件遵守[版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.5`，`rule_version=routine-0.5.0`。虚空主题只提供跨服服务与档案线索，不把运营池作为虚空突破资源来源。

| 系统 | 稳定键/准入 | 参数与结算 |
|:--|:--|:--|
| 灵木 | `ritual.spirit_tree.void`：完成虚空补给合同 | 35 日周期；每日维护 1 次；灵石 600–900、补给券 1、档案线索 |
| 机缘寻宝 | `gacha.fate.void_archive`：炼虚 L1 或商会档案资格 | 单抽 500、十连 4500；池只出档案、服务、展示和普通补给；保底 40 |
| 行卷 | `pass.wayfaring.void` | 50 级、35 日；跨服商会/修复计点；奖励不可交易虚空资产 |
| 功业/道号 | `achievement.void_logistics` | 交付 10 次补给得 `title.void_logistician`、商会服务等级 +1 |
| 道契 | `dao_contract.void_monthly` | 日补给与精力权益；不发虚空锚、虚晶、虚力 |
| 七日目标 | `quest.seven_day.void` | 只给非炼虚角色可参加的供货/档案目标；炼虚可走导航目标 |
| 密令 | `code.void_repair` | 总库存 100；发补给物/维修券，不能发跨境突破物 |

所有机缘/行卷奖励保存赛季和版本快照；不同服务端的业务日按统一规则服务器生成。
