# 核心：社交域

社交域负责宗门、师徒、队伍、委托服务和后置道侣关系。

当前已开放宗门基础成员闭环：创建宗门、提交入宗申请、管理职位审批、离宗冷却和宗门资料卡；
宗门战最小闭环：每周两轮、每轮 30 分钟，宗主报名并冻结最多 10 名成员，使用已归属来源 operation
记录占点、击败、运输和维修贡献，轮次结束结算宗门功勋，合格个人领取或自动获得世界功勋；
以及师徒邀请、接受/拒绝、过期和毕业奖励；双人探索队伍、普通 4–5 人副本队伍和三人竞技队伍的创建、邀请、接受、全员确认、状态查询、退出和队长转移。
已确认的双人或普通多人队伍可由队长发起自动 PVE，战斗域保存全体成员快照、独立资产锁、行动回放和每成员唯一奖励；界隙队伍支持 2–5 人跨界副本，开始前原子扣除体力/门票并冻结跨界快照。
三人竞技队伍可发布对称 3v3 或参与 2v3 竞技场快照；个人 `arena.three_realms` 已开放元婴与许可门槛下的同阵营/跨阵营匹配。v0.5 跨服宗门战本地周赛已开放虚空堡垒准入、30/15 名额、服务端战争机关自动回合、积分反刷、公共奖励箱和周奖励；联邦前置仍负责 roster 快照与远端结算审计。跨服匹配、身份合并、玩家间资产转移以及跨服 PvP 仍未开放，具体边界见[当前开发状态](../../current-status.md)。
