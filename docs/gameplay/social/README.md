# 核心：社交域

社交域负责宗门、师徒、队伍、委托服务和后置道侣关系。

当前已开放宗门基础成员闭环：创建宗门、提交入宗申请、管理职位审批、离宗冷却和宗门资料卡；
以及师徒邀请、接受/拒绝、过期和毕业奖励；双人探索队伍的创建、邀请、接受、双方确认、状态查询、退出和队长转移。
双方确认后可由队长发起双人自动 PVE，战斗域保存全体成员快照、独立资产锁、行动回放和每成员唯一奖励；
三人以上队伍/匹配、宗门扩展、玩家间资产转移以及 PvP 匹配仍未开放，具体边界见[当前开发状态](../../current-status.md)。
