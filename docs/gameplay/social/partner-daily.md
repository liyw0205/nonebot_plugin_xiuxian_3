# 道侣同行日课

道侣同行日课自 `v0.1.62` 开放，是一条独立的双人活动链，不是双修结算或道侣终局协作的扩展奖励。首期仅开放经内容白名单确认的山野资源脉取材；玩法不创建新战斗，不共享或转移资产，不改变关系、境界、修为或终局状态。

## 玩家流程

| 命令 | 用途 |
|:--|:--|
| `道侣日课`（别名 `同行日课`） | 查看 UTC 日期、本人和道侣进度、任务期限及各自领取状态 |
| `道侣日课记录 [页码]`（别名 `同行日课记录`） | 每页五份本人历史任务，按创建时间倒序查找详情与双方领取记录 |
| `开始道侣日课` | 开启或恢复当前有效关系的当日日课 |
| `领取道侣日课 [任务号]` | 双方都达标后，由本人领取自己的奖励 |

开启时双方必须有同一条 active 道侣关系，角色均处于可参与状态，且没有已结束的终局角色状态。每段关系每天 UTC 最多开启一份任务。开启会冻结任务文案、来源白名单、每人目标、截止时间和奖励；同日再次开启返回原任务。上一任务仍进行或尚有一方未领取时，不会覆盖未结任务。

双方必须在任务开启之后，各自成功完成一次白名单资源脉的 `deposit.extract`。`资源脉预览`、勘察、养护、失败取材、帮助、旧操作重放和同一 operation 重放均不计进度。只有真实取材事务已写入来源 operation receipt 后，才在同一 SQLite 事务写入对应玩家的日课证据。任何证据投影错误都会回滚来源扣费、材料和储量变更。

一方不能代做另一方活动或代领另一方奖励。双方都完成后各自使用 `领取道侣日课`；资产、个人领取记录和 operation receipt 原子提交。相同 operation 与输入重放原结果；同一 operation 改输入冲突；不同 operation 再领则明确返回已领取。奖励写入失败会整体回滚，修复后可以安全重试。

`道侣日课记录` 不要求当前仍有道侣，关系暂停、解除或更换后仍可查阅本人参与的旧任务；他人的任务不会出现在列表。页码范围为 1 至 10000，空页可返回上一页。详情链接携带任务号，按冻结快照显示原有规则、贡献及领奖状态，不因当前规则关闭而丢失历史。历史查询和翻页均只读，坏快照或不完整流水会明确失败，不跳过损坏任务或补写奖励。

## 内容与快照

静态规则位于 `data/社交/道侣日课.json`，类型为 `partner_daily_task`，唯一键为 `task.partner.daily.fieldwork`。内容声明任务状态、稳定键、名称/描述、状态与历史命令别名、真实来源类型、允许资源脉、双方目标、任务时限、UTC 每日额度、世界功勋与物品奖励。任务别名直接由此规则注册到 QQ/OneBot 共用 router，不再在 Python 重复维护；必须是无空白的单词命令，日课内部别名重复会在内容验载时失败，与现有命令冲突会阻止 router 注册。历史命令别名只影响路由，不进入已创建日课的冻结快照。严格解析拒绝未知/缺失字段、大小写归一后重复别名、错误类型/范围、非白名单来源、缺失资源引用、不存在物品及终局奖励物品。

`partner_daily_tasks`、`partner_daily_evidence` 和 `partner_daily_claims` 由可重复执行的 additive SQLite migration 创建，不更新玩家、关系、双修、事件、资产或既有 operation 表。唯一约束分别保证每段关系每天一个任务、每个来源 operation 只投影一次、每名玩家每个任务最多领奖一次。新增官方种子通过 `scripts/seed_migrations.json` 记录实际 Git 来源和新旧 SHA-256；安装升级保留未识别的自定义文件。

任务规则快照用严格结构与哈希读取，不从当前规则补默认值。关闭现行规则会阻止创建新任务；合法修改只影响新任务。既有任务仍可查询、追加符合其冻结来源的证据、恢复同日任务和按冻结奖励领取。查询只投影本人/道侣进度与道号，不暴露平台 ID 或内部玩家 ID。道侣关系暂停、解除或切换后，旧任务不再接受新来源证据或发放新奖励。

## 状态与验证

```text
open -> claimable -> completed
  `----> expired
```

`open` 仅在截止前接受新证据；双方达标后进入 `claimable`；一方领奖后仍可由另一方独立领取；两侧均领取后成为 `completed`。过期任务不再增加进度，未达标任务不发奖励。状态查询只读，不因跨日或超时偷偷写入业务状态；下次开启可显式回收过期开放任务。

验收必须通过共享命令 router 分别经 QQ 官方与 OneBot V11 走完整玩家链，并直接检查关系、任务、证据、operation 和玩家资产表。覆盖旧 receipt、重复开始/取材/领奖、同一秒开启与取材、失败回滚、并发双人进度/领奖、重启恢复、规则关闭后的快照、关系失效、停用角色、过期/跨日、坏内容与迁移重复初始化。适配器模拟只验证路由和结果合同，不代表真实平台投递。
