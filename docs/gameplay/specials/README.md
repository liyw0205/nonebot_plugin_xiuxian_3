# 核心：特色玩法域

特色玩法域提供六类可长期重复或累积的目标：挂机收益、派遣任务、图鉴收集、试炼塔、竞技场和多结局剧情线。它们是核心玩法，不属于已移除的媒体/小游戏/第三方娱乐系统。

当前六类玩法均处于合同或锁定阶段，尚未开放运行时命令；道历、机缘寻宝和问道行卷属于
`gameplay/routine/`，不要在本域重复实现。试炼塔、竞技场和需要战斗的图鉴/剧情必须等待
自动回合战斗门槛，状态以[当前开发状态](../../current-status.md)为准。

## 共同边界

1. 挂机、派遣、图鉴、竞技场和故事本身不得直接写入 `realm_cultivation`、`total_cultivation`、突破准备度、突破概率或跨境材料。
2. 试炼塔可调用既有战斗域；其首通奖励受楼层/赛季唯一限制，不得通过重试、掉线或回放重复领取。
3. 竞技场采用异步快照对战，默认不强制真人实时在线，不允许匹配到未明确发布的战斗快照。
4. 图鉴条目只记录发现事实和版本；收集奖励是配方线索、地区名望、展示/故事开放或受限服务资格，不提供永久战斗属性。
5. 多结局剧情的关键选择不可由重试改变；故事结局与飞升终局分开，除非 v0.6 明确将其作为前置快照读取。
6. 所有离线/计时收益以服务端 Clock、会话开始/结束时间和最大可领取窗口为准；客户端时间不能扩大收益。
