# 核心：特色玩法域

特色玩法域提供六类可长期重复或累积的目标：挂机收益、派遣任务、图鉴收集、试炼塔、竞技场和多结局剧情线。它们是核心玩法，不属于已移除的媒体/小游戏/第三方娱乐系统。

挂机收益四条 v0.1 路线、派遣三条 v0.1 任务、v0.1 基础图鉴、雾隐试炼塔
`tower.mist_trial` 1–45 层（v0.1 1–30，v0.2 扩至 45）、异步 `arena.spar`、`arena.practice`、`arena.rank`、
`arena.three_realms`、`arena.team` 和 `story.xuantian.road` 三分支切片均已接通。
试炼塔支持首通/练习、层段准入、每日/每周限额、特殊奖励、恢复和 operation 重放；QQ 官方与
OneBot V11 覆盖 5/10/15/20/25/30/35/40/45 层首领、战败、额度、功业、境界边界及全部特殊奖励领奖。
三界塔 `tower.three_realms` v0.3 单人 1–20 层已开放，QQ 官方与 OneBot V11 覆盖完整顺序首通、
10/20 层阵营首领、主线许可、每层 UTC 周 2 次配额、练习、图鉴、幂等及资产隔离；v0.4 21–40 层和双人规则尚未开放。
故事支持查询、寻仙问道后
开始、商路/守望/药圃证据门槛、选择锁定、结局领奖和来源快照；两个适配器均覆盖三分支、未达成
拒绝、不可改选、幂等和奖励边界。其他后续版本图鉴/故事和虚空塔尚未开放。

图鉴覆盖地点、基础材料、已登记异兽、入道/公开观察道途、派遣路线、竞技场挑战、试炼塔
五/十层首通和集合里程碑；v0.2 以后的图鉴内容仍按对应切片开放。派遣超过结束时间 24 小时后
自动恢复结算，并为七日目标 D6、首次派遣功业及称号投影来源。
道历、机缘寻宝和问道行卷属于 `gameplay/routine/`，不要在本域重复实现；状态以
[当前开发状态](../../current-status.md)为准。

## 共同边界

1. 挂机、派遣、图鉴、竞技场和故事本身不得直接写入 `realm_cultivation`、`total_cultivation`、突破准备度、突破概率或跨境材料。
2. 试炼塔可调用既有战斗域；其首通奖励受楼层/赛季唯一限制，不得通过重试、掉线或回放重复领取。
3. 竞技场采用异步快照对战，默认不强制真人实时在线，不允许匹配到未明确发布的战斗快照；`arena.spar`
   的胜负只改变竞技场积分和统计，不转移玩家资产。
4. 图鉴条目只记录发现事实和版本；收集奖励是配方线索、地区名望、展示/故事开放或受限服务资格，不提供永久战斗属性。
5. 多结局剧情的关键选择不可由重试改变；故事结局与飞升终局分开，除非 v0.6 明确将其作为前置快照读取。
6. 所有离线/计时收益以服务端 Clock、会话开始/结束时间和最大可领取窗口为准；客户端时间不能扩大收益。
