# 核心：特色玩法域

特色玩法包括离线挂机、派遣任务、图鉴收集、试炼塔、竞技场和多结局剧情。挂机与派遣分别按路线、
时长、每日/每周配额和服务端结算发放所得；取消、逾时及恢复遵守各自的状态机。图鉴只记录已验证的
地点、材料、战斗和服务来源，不替代物品或剧情目标。试炼塔按层解锁并限制挑战次数，竞技场使用冻结的
对战快照，故事线在开始时冻结前置、选择和奖励。当前开放范围见[当前可用能力](../../availability.md)，
具体准入、命令与结算规则见下方领域说明。

道历、机缘寻宝和问道行卷属于 `gameplay/routine/`，不在本域重复定义。

## 共同边界

1. 挂机、派遣、图鉴、竞技场和故事本身不得直接写入 `realm_cultivation`、`total_cultivation`、突破准备度、突破概率或跨境材料。
2. 试炼塔可调用既有战斗域；其首通奖励受楼层/赛季唯一限制，不得通过重试、掉线或回放重复领取。
3. 竞技场采用异步快照对战，默认不强制真人实时在线，不允许匹配到未明确发布的战斗快照；`arena.spar`
   的胜负只改变竞技场积分和统计，不转移玩家资产。
4. 图鉴条目只记录发现事实和版本；收集奖励是配方线索、地区名望、展示/故事开放或受限服务资格，不提供永久战斗属性。
5. 多结局剧情的关键选择不可由重试改变；故事结局与飞升终局分开，除非 v0.6 明确将其作为前置快照读取。
6. 所有离线/计时收益以服务端 Clock、会话开始/结束时间和最大可领取窗口为准；客户端时间不能扩大收益。
