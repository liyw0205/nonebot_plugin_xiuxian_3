# 特色玩法：图鉴收集

图鉴记录玩家首次确认发现的世界事实：地点、材料、敌人、道途技艺、作物、商路、道统服务、故事人物/结局和塔层首通。它提供长期收集与知识目标，不出售数值强度，不能成为修为或突破的替代来源。

`我的图鉴 [分类或关键词]` 只读查询，`领取图鉴里程碑 <序号>` 领取已集齐的见闻之赏。地点、材料、异兽、道途、行旅、秘境、试炼和故事记录，均由相应经历自然收入图鉴；未曾亲历的见闻不会提前显露。

三界塔首通可记下所历楼层和阵营往事。故事取自入塔时亲历的阵营，不受事后选择左右，也不改变道途与声望。

飞升或留界结局由终局用例在结局确认的同一事务中收入对应的公开结局见闻：
`codex.ending.public_ascend` 或 `codex.ending.public_remain`。见闻只记录亲历的结局与当时的展示名，
不授予修为、道果、飞升凭证或其他终局资源；同一结局选择的 operation 重放不会重复写入。内容改名或关闭后，
已确认结局仍按首次见闻快照展示，新结局在条目关闭时拒绝确认。

六大道域的传承、远古洞天、祖灵殿和领域前线均可收入图鉴。远古洞天与祖灵殿只记首度探成，领域前线则在亲自立功领奖后记下。集齐远古洞天、祖灵殿和领域前线三则见闻，可得「六域战策」与「观域居所陈设」。

道统服务现有见闻分别由道源秘境首通、道统服务派遣成功和同赛季第三次公共建设结算核验收入；查询和未达结算条件的经历不会提前点亮。

## 1. 条目和发现

`specials.record_codex_discovery` 只能由白名单的已结算 operation 调用：地点到达、物品首次获得、敌人战斗结算、作物收获、派遣成功、塔层首通、竞技场首次对局、故事节点/结局确认。适配器和前端禁止直接“点亮”。

| `codex_category` | 首见来源 | 可显示内容 |
|:--|:--|:--|
| `place` | 成功到达地点 | 地点简介、境界门槛、行旅提示 |
| `material` | 已结算获得物品 | 来源地区、用途、绑定说明 |
| `creature` | 战斗结算或观察派遣 | 敌人特征、技能摘要、图鉴编号 |
| `craft` | 学习配方或完成订单 | 配方方向、工具/设施提示 |
| `route` | 运输/派遣/探索结算 | 路线风险、贸易提示 |
| `dispatch` | 派遣成功结算 | 任务线索与首次完成时间 |
| `service` | 公共建设或其他已登记的道统服务结算 | 服务见闻与亲历记录 |
| `story` | 锁定节点/结局 | 已见文本摘要、不可逆选择说明 |
| `challenge` | 塔层首通/竞技场首次结算 | 战术记录、赛季/楼层历史 |

首次发现写入 `CodexEntry`（运行时表为 `codex_entries`），首见来源、时间和展示名不可变；后续同条目只更新最近发现时间，查询不更新时间。隐藏条目只返回 `unknown` 和允许的提示，不泄漏未来内容/敌人/故事选择。

机缘寻宝所得通过既有材料投影收入图鉴：只记录本次实际获得、数量为正且已有开放材料条目的物品，
不会为灵石、名望、丹药或凭证等其他奖励另造材料条目。首见留存该次 operation、奖池键和材料名称；
已有首见不因再次寻宝或其他来源获得同一材料而被改写。扣费、所得、保底、抽取记录、图鉴和 operation
在同一事务内提交，任一写入失败全部回滚。原请求只读回放，不在重放时补齐历史漏记的条目。
保持引用闭合的内容改名或关闭后，历史首见仍按原名展示；关闭条目须同步处理依赖它的开放里程碑。

公共建设只有在个人贡献达到项目结算门槛并成功领取项目奖励时，才收入内容记录声明的 `service` 条目；列表、贡献中、失败、训练傀儡和切磋观战都不会提前点亮。项目物化时冻结图鉴稳定键和展示名，内容改名或关闭不影响已完成项目的历史见闻，新项目则必须通过当前内容校验。

道源任务“建设”只在本赛季第 3 次本人公共项目达标结算核验成功时收入 `codex.dao.service_settlement`；前两次仅推进任务进度。任务奖励、事件、进度、图鉴和 operation 同事务提交，历史 operation 按首次见闻快照回放，内容改名或关闭不影响已确认见闻。

竞技场结算由服务端把参与、胜利/落败/平局分别投影为 `challenge` 类条目，并同步写入
`activity_events`。投影使用对局 operation 和 `(match_id, player_id)` 唯一约束；重复结算只回放，
不会重复创建图鉴或名望。

## 2. 集合里程碑

每份见闻之赏对每名修士只可领取一次。所赐仅限地区名望、服务信誉、配方线索、路线提示、居所陈设、故事可见性或受限服务资格；不授修为、突破丹、战力、跨境资格、道果或飞升功勋。

| 里程碑示例 | 条件 | 奖励 |
|:--|:--|:--|
| `codex.xuantian.materials_5` | 玄天材料 5 条 | 城镇名望 +5、`hint.herb_route` |
| `codex.town_services_3` | 城镇服务/路线 3 条 | 服务信誉 +3、运输委托额外展示 1 条 |
| `codex.paths_6` | 六道途首见 | 道途百科页解锁，不给属性 |
| `codex.mist_challenge_10` | 试炼塔 10 层记录 | 塔路线提示、展示徽记 |

图鉴预览与搜索皆为只读，不会增添见闻或消耗资源。领取时会一并记下已集齐的条目；地区名望经统一角色状态事务按地点内容中的上限结算，领奖记录、实际所得与 operation 同事务保存。达到上限时仍可领取其他见闻解锁，但名望只记实际增加的部分，原有名望不会被扣回；已领取条目展示账簿中记下的实际所得。

名望数据损坏或奖励写入失败时，整次领取回滚且不留下领奖记录或 operation，同一请求可在修复后重试。成功领取的名称、解锁展示和实际所得随 operation 冻结；内容关闭或调整、进程重启后，原请求仍按当时结果重放，不重新读取现行里程碑配置。

## 3. 隐私、关闭与验收

图鉴只记修士亲历的见闻；斗法中对手的名号会隐去身份，未曾经历的故事不会展露。

验收：同一来源重放不双建条目且不补写历史漏记；伪造前端条目拒绝；隐藏内容不泄漏；集合奖励唯一且不含战斗/修为收益；保持引用闭合的内容调整不改历史首见；机缘结算故障不留下扣费、所得或图鉴；管理员修复只追加审计说明。
