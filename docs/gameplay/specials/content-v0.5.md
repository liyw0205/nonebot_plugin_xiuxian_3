# v0.5 特色玩法内容基线：虚空导航与跨服演练

本文件遵守 [版本内容开发合同](../../content-development-contract.md)。`content_version=content-0.5`，`rule_version=specials-0.5.0`。虚空特色玩法保留供货/观察入口：非炼虚角色可参加补给、图鉴、练习与故事，不会借此获得虚空锚、虚力或炼虚突破资格。

| 类型 | 稳定键与准入 | 参数与结算 |
|:--|:--|:--|
| 挂机 | `idle.void_supply_watch`：完成 `void_supply.*` 合同 1 次 | 12h；灵石 140–220、商会票 1、图鉴线索；超时灵石 70 |
| 派遣 | `dispatch.void_supply_convoy`：供货信誉 >=60 | 8h；普通补给物；成功灵石 500、虚空商会名望 +6；failed 返 50% 可返物 |
| 派遣 | `dispatch.archive_translation`：图鉴虚空档案 3 条 | 6h；故事/图鉴线索、信誉 +3；不产档案/锚/虚晶 |
| 图鉴 | `codex.void.route_*`、`codex.void.archive_*` | 虚空图鉴 8 条：跨服商会预览、展示舰标；不开放航行 |
| 试炼塔 | `tower.void_spire` 1–30：炼虚 L1 或虚空补给名望 600 | 每周 2 次；首通常规材料/图鉴/名望；不产锚/晶体/装备 |
| 竞技场 | `arena.void_drill`：炼虚 L1 或战术观察许可 | 20 回合中性虚空模拟；赛季 28 天；称号/名望/服务资格 |
| 剧情 | `story.void_archive` | 记录者/护航者/归乡者分支；结局给档案展示、商会服务权限、名望 20 |

所有虚空路由池只决定延误/图鉴线索/普通报酬，不创建真实航道、战斗或虚空资源会话。
