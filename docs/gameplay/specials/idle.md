# 特色玩法：闲居历练

闲居历练是离线采集与看守安排，不会自动修炼。路线、门槛、耗时、次数、消耗、完整所得和逾时所得由 `data/生活/生活.json` 与 `data/奖励/奖励.json` 提供；代码只负责通用准入、计时、抽取、资源事务和恢复。

## 会话与结算

玩家可用 `挂机预览`、`开始挂机 <路线名> [工具或作坊槽位]`、`领取挂机 [安排编号]` 与 `取消挂机 [安排编号]` 操作。预览是只读的。开始事务会检查角色、路线门槛、并行长行动、该路线当日结算次数、资源、工具和作坊槽位；全部通过后才扣除资源、锁定工具/槽位并写入会话与 operation。

完整与逾时奖项、路线名称、工具耐久消耗、地点名望上限和随机种子都在开始时冻结。每条路线分别计算每日次数，完成或逾时所得归入安排开始之日，撤回不占次数。后续改动或关闭内容只影响新安排；领取和历史 operation 重放只读现有快照。名望、灵石、物品、耐久、图鉴、会话状态和 operation 在同一 SQLite 事务内提交。

```text
claimable_at = started_at + duration_seconds
max_claim_at = started_at + min(duration_seconds + 24h, 48h)
```

`claim_at` 前不能领取；`claim_at` 至 `max_claim_at` 按冻结的完整所得结算；超过最大窗口按冻结的逾时所得结算。时间只取服务端时钟和会话列，不采信客户端时间。完成与逾时结算都只占一次当日次数，不补发或累积离线时长。

数据库状态在领取前保持 `running`；是否可领取由保存的 `claim_at` 与当前服务端时间计算。领取后为 `claimed` 或 `expired`，取消后为 `cancelled`。开始后 60 秒内可取消，事务会返还成本和工具、释放作坊槽位；之后不可取消。工具只有完整领取时才扣除配置耐久，逾时领取不扣。

## 寻道期路线（v0.10）

此前 11 条闲居路线全部落在凡人（4 条）与入道（7 条）两档，寻道期（`seeker`，即寻仙问道之后、入道之前）没有任何闲居安排。v0.10 追加两条 `stage: seeker` 路线：

- `idle.seeker_herb_tending`（灵田照看）：需有效居所、消耗 1 精力、4 小时、每日 1 次；完整所得为灵草，**并在一份全新 `codex.route.seeker_herb_tending`（灵田照看见闻）图鉴条目上记下首次见闻**，使其成为「闲居也能点亮图鉴」的真实入口；逾时保底同样记下该见闻。
- `idle.seeker_town_inquiry`（镇中问询）：需青石镇名望 ≥10、消耗 1 体力、3 小时、每日 1 次，使用独立加权奖池。

两条路线使用既有 `stage`/`active_residence`/`local_reputation` 门槛与既有通用闲居事务，不新增表、字段或命令；奖励只含灵石、既有材料、地方名望与既有 `codex.*` 条目，`闲居预览`/`开始挂机` 自动收录。

## 事务与恢复

开始、领取、取消分别使用 operation ledger。相同编号及输入重放原结果；同编号不同输入返回冲突。内容或奖励引用无效、玩家名望 JSON 损坏、奖励写入或 operation 写入失败时，整笔事务回滚；修复原因后可用原领取 operation 重试。进程中断后，运行中的安排仍由数据库保存，玩家再次领取时按已冻结的完整/逾时奖项恢复结算。

文本、QQ 官方与 OneBot V11 均调用同一 application 和 repository；玩家文案只展示路线、物资、地点名望与见闻，不展示稳定键、操作编号或内部状态。切磋与训练傀儡保持只读观战，闲居历练不介入正式 PvE/PvP 结算。

资源写入继续使用共享资产工具。超出 SQLite 有符号 64 位范围的 Python 整数以十进制字节
