# 特色玩法：挂机收益

挂机是受限的离线采集/看守安排，不是自动修炼。它只结算常规材料、灵石、地方名望和图鉴线索；不得发放修为、突破准备度、突破材料、战斗属性、道果或飞升功勋。

## 1. 会话与结算

`specials.assign_idle` 输入路线键、可选工具/设施、`operation_id`。预检查角色 active、无其它 active 挂机、无互斥战斗/突破/移动/派遣锁、路线开放且体力/设施要求满足。开始时固定路线、角色地点、工具耐久、设施、路线池、开始时间、`claim_at`、`max_claim_at`、版本与输入摘要。

```text
claimable_at = started_at + duration
max_claim_at = started_at + min(duration + 24h, 48h)
```

`claim_at` 前返回 `IDLE_CLAIM_TOO_EARLY`，不结束会话；`claim_at` 至 `max_claim_at` 内按完整收益结算；超过 `max_claim_at` 只按路线定义的最低保底结算，未产出部分作废，不能累积或补发。任何离线时长都不以客户端时间计算。

| 状态 | 可用行为 | 资产语义 |
|:--|:--|:--|
| `assigned` | 仅查看/取消确认窗口 | 未扣路线成本 |
| `running` | 查询进度 | 工具/设施锁定，不能领取 |
| `claimable` | 一次 `claim_idle` | 原子发奖并完成 operation |
| `claimed/expired` | 只读 | 不可重开、不可重复领奖 |

创建后 60 秒内可取消，释放工具/设施并全额返还开始成本；之后不可取消。恢复任务只能按保存的时间/池结算，不可重新抽取。

## 2. 路线类型与资源边界

每角色同时 1 条挂机，默认每天最多 2 次结算；高版本可增加路线而不增加并发槽。工具耐久只在成功结算时扣除，预检查/超时/重复领取不能重复扣。

| `idle_route_key` | 主要用途 | 允许产出 | 禁止产出 |
|:--|:--|:--|:--|
| `idle.town_errand` | 城镇跑腿/看店 | 灵石、地方名望、木材/灵米 | 修为、突破物、稀有装备 |
| `idle.herb_watch` | 药圃看护 | 血草、灵叶、种子线索 | 修为、丹药成品、突破丹 |
| `idle.workshop_care` | 工具/作坊看守 | 阵砂、木材、维护券 | 生产成品、质量、熟练度 |
| `idle.route_scout` | 商路观察 | 灵石、路线图鉴线索、运输信誉 | 货物、跨界资格、战斗奖励 |

收益池以路线为单位、在分配时快照。池可以有“空手”结果，但必须保证最小保底；不会因气运/道途让单次产出突破路线表上限。设施最多提供 `duration -2000 bp` 或一个额外非保底材料抽取，二者不叠加。

## 3. 权限、观测、关闭与验收

角色本人可分配/领取；管理员仅可查看、关闭路线或执行恢复。记录 `idle_assignment_id`、路线、开始/领取/最大时间、随机池、抽取、成本、工具耐久、设施、结果、版本和 operation。

关闭内容时停止新分配；running 会话到 `claimable` 后按原池结算，超过最大窗口走最低保底。验收：同一领取 operation 不双发；时间篡改无效；超时不累计；路线/工具冲突不扣资源；收益日志不含修为/突破/终局资源键。
