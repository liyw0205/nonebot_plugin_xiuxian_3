# 特色玩法：多结局剧情线

剧情线由当前内容包定义分支、经历门槛、展示文字和结局。玩家通过探索、图鉴、派遣、服务、塔层、阵营
和明确选择推进；关键选择以 operation 记账。故事结局可以影响地方名望、图鉴、居所外观和其他明确列出的
展示/准入状态，但不能直接提升境界、授予突破资格或改写飞升终局。

## 1. 玄天之路

正式命令为 `剧情线`、`开始剧情`、`选择剧情 <商路|守望|药圃>` 和 `领取剧情结局`。完成寻仙问道后
可以开始。商路需要三次不同的已交付城镇委托；守望需要两场已结算胜利战斗；药圃需要两次灵田收获或
两次成功药材派遣。内容记录 `story.xuantian.road` 定义分支和来源门槛，奖励记录定义结局名望。

选路事务冻结经历来源 operation、已完成经历、结局键、旗标、图鉴条目与类别、居所外观、名望地点与上限、
展示名称及实际奖励。分支锁定后不能改选；已锁定的故事不受后续内容修改或关闭影响。领奖不再解析当前
分支或奖励配置。

结局奖励、名望封顶、角色旗标、图鉴发现、结局记录和 operation 在同一个 SQLite 事务内提交。共享角色
状态内核负责奖励校验和名望增减；领域事务负责来源、剧情记录与图鉴投影。结果和玩家回复只记录封顶后的
实得名望。损坏的名望 JSON 或事务中任一写入失败都会整体回滚，同一 operation 可在故障解除后重试。

状态为 `available -> active -> ending_pending -> ended`。`active` 期间读取本人已结算经历；未满足条件
不会锁定选择，同一分支可幂等重放，改选会被拒绝，同一角色不能再次开启已完成的故事。玩家可见回复不
展示内部经历键、稳定键或请求编号。

## 2. 结局边界

结局可写入地方名望、图鉴发现、剧情旗标和居所外观；不得写入修为、突破材料、跨境许可、永久战斗属性、
道果、飞升功勋或终局状态。结局按 `story_key + ending_key + player_id` 唯一，不能通过重开同一故事绕过
互斥选择。

故事可读取既有道途、名望、图鉴、塔层、派遣、竞技场、关系与探索经历，但只接受本人已结算的服务端来源。
飞升/留界仍由终局用例结算，故事旗标不能替代天劫、道果进度或最终战。

## 3. 隐私、恢复与验收

剧情文本与私密旗标默认仅玩家可见；公共展示只允许玩家显式公开的结局标题。恢复时以运行记录中冻结的
经历来源、旗标、奖励、名望上限和展示快照为准，不因当前名望、装备或内容调整重算旧选择。

验收覆盖：不能直接跳到结局；选择和领奖重放稳定；互斥结局不能共存；奖励不含境界、突破或终局资源；坏
JSON 与事务中断不留下部分结算；QQ 官方和 OneBot V11 覆盖配置变化、重启恢复和真实来源；飞升用例只读取
允许的故事旗标，不接受故事写入终局状态。
