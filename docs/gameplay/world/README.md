# 核心：世界域

世界域负责三界、洞天福地、地点定义、玩家位置和移动。

当前运行时开放玄天新手城、近郊、灵泉谷和雾隐洞天一层的移动会话；道源门和天劫台的
终局前置移动也已接入。v0.2 世界切片另外开放云城/阵堂普通移动、云舟洞天二层与魔界引导
航线，以及抵达魔界深渊门后的风险确认；云铁采集、云舟试炼和洞天二层探索战斗已在探索域接入，分别要求矿区许可、云舟渡口/金丹和已抵达二层；阵堂迷雾屏障生产已接入，生产入口仍会重新校验宗门成员/教学邀请。v0.3 已开放魔界堕落遗迹单人探索切片、`xuantian.war_front` 活动窗口移动、魔渊集市移动切片和妖界万兽山移动切片；领取 `quest.demon_main_1` 后才获得 `access.demon.fallen_ruins`，正式移动会再次校验该权限并冻结版本；魔渊集市要求元婴 L1、魔界声望 200，万兽山要求元婴 L1、妖界声望 200，两者都在开始事务中冻结准入快照。固定 `trade.xuantian_to_demon` 已在集市接入，输出魔核绑定 24 小时并按周限次；固定 `trade.xuantian_to_beast` 已在万兽山接入，输出妖血绑定 24 小时并按周限次；首条妖兽契约生产已接入，绑定成品独立占用 24 小时契约槽；战场移动还要求活动窗口和元婴 L1。三界贸易、其他正式契约配方和跨界多人副本仍关闭；心魔独立事件已通过事件域投影接入。终局战胜利直接把发起者放到飞升路并设为 `ascension_ready`，
留界结局仍可从飞升路前往留界殿；飞升路的移动凭证规则保留为独立内容合同，不参与终局战。
终局完整资产来源与赛季结算仍处于 `partial`。魔界、妖界、
其他洞天以及跨界路线仍是内容合同；完整边界和当前状态见[当前开发状态](../../current-status.md)。
