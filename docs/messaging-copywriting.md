# 消息与文案规范

角色命令的 `CommandResult.message` 统一按 Markdown 编写。消息要先告诉玩家发生了
什么，再展示少量关键资料，最后给出一个明确的下一步；不要把内部模块名、异常堆栈、
数据库字段或实现说明直接展示给玩家。

## 玩家文案边界

玩家看到的是修仙世界中的人物、地点、物品、行动和结果，不是开发者调试面板。整条消息应
保持同一种叙述语气；不得先用修仙叙事、再夹入开发说明或程序参数。`data/**/*.json` 中的
`name` 与 `desc` 也写给玩家看，只描述世界内的事物和作用，不写实现步骤或字段说明。

## 文案风格

采用清楚、克制的游戏文案：先直说发生了什么，再用少量修仙语汇补足氛围。不要把半段
网文叙事和半段开发公告拼在一起，也不要为了“仙侠感”堆叠古风套话。角色结果、系统提示
和错误说明都以玩家能立即理解为准，不模拟开发者、运营人员或调试工具的口吻。

- 不展示 `bp`、JSON、配置、快照、运行时、数据库、版本号、稳定键、schema、operation、适配器等内部词语。
- 不把 `risk_reduction_bp`、`state_bp`、`content_version` 之类字段名翻译成中文后继续照搬；先把数值换算成玩家熟悉的百分比、修为、体力或时长。
- 命令语法可以保留，但要用自然中文给出具体可执行命令，不讲参数解析、分支或实现方式。
- 错误消息只解释角色遇到的阻碍和能采取的行动；内部失败原因写日志，不要把“数据库繁忙”“请求冲突”等实现状态包装成仙侠台词。
- 避免空泛套话、连续堆叠古风修饰和混杂的网络/开发口吻；优先短句、明确结果、符合当前场景的少量修仙语汇。
- 不把开发进度写成世界设定：避免“当前版本暂未接入”“本功能暂不支持”“奖励池已配置”“触发了某某逻辑”等措辞；确实未开放时，只说明角色当前无法做什么、原因和可执行的下一步。
- 不让同一句在“道友/灵气/仙途”和“模块/功能/接入/配置/数据”等语域间跳转；玩法概念只有在角色能自然理解时才使用。

反例：`云灵茶效果已冻结，state_bp +500 bp，将在 cultivation_session 中消费。`

建议：`一缕清灵仍在经脉间流转。下一次修炼所得修为提高 5%。`

尚未开放时，说明眼前的阻碍与可以继续做的事，不提开发安排；例如：`灵泉谷就在眼前，
泉眼尚未开启。先回新手城继续修行。`

## 格式

- 使用 `##` 作为一次命令结果的标题。
- 使用项目符号列出道号、阶段、位置、灵石和资质等字段。
- 道号和重要结果使用粗体；内部 ID、稳定键和数据库字段不对玩家展示。
- 下一步使用引用块 `>`，一次只推荐一个动作。
- 资质、奖励等同类数据分组展示，避免把内容挤在一行；阶段、状态、位置和资质名称使用中文文案。
- 展示数值使用玩家熟悉的单位；基点按百分比换算，持续时间用分钟/小时，内部单位和字段名只留在代码与测试中。

## 适配器行为

- QQ 适配器使用 QQ 原生 Markdown 消息段。
- QQ 的蓝字命令链接和自定义按键只在 QQ 消息中发送。
- OneBot V11 不发送 QQ 消息段，自动移除 Markdown、蓝字链接和按键后发送普通文本。
- 未声明 Markdown 能力的适配器同样退化为普通文本。
- 消息格式失败只影响展示，不得回滚或重复执行角色 operation。

## 当前命令示例

`开始修仙`、`寻仙问道`、`完成引导`、`前往近郊`、`返回新手城`、`选择道途`、`修仙改名`
和 `我的状态` 的成功结果都遵守上述结构；修炼循环还包括 `开始修炼`、`结算修炼`、
`开始修炼 灵泉`、`结算修炼`、`恢复修炼`、`取消修炼`、`晋升境界` 和 `恢复状态`。
生产命令包括 `生产预览 <配方>`、`开始生产 <配方>`、`领取生产`、`恢复生产` 和 `净化污染`。
`我的修仙信息` 是 `我的状态` 的别名。用户可见资料使用道号，不展示平台用户 ID；
未取道号时显示“未命名”。错误消息保持简短，只说明原因和可执行的修复动作。

灵泉谷教学快捷入口使用 `前往灵泉谷`；正式移动使用 `前往 灵泉谷`，并在移动完成后发送
`结算移动`。成功时说明抵达地点和剩余体力；灵泉修炼成功时说明 15 分钟时长、3 点体力、
基础修为 70 和每日剩余次数。准入不足、位置不符或当日次数
用尽时，只展示中文原因和可执行的下一步，不展示地点键、模式键或规则版本。

生产结果只展示配方名称、质量、获得物品、返还材料和剩余精力，不展示 recipe/item 稳定
键、订单 ID 或平台用户 ID。失败时明确说明没有获得成品，并列出实际返还的材料。

## 引导与入道示例

```markdown
## 教学采集完成

**未命名**，你在玄天近郊采得 **止血草 ×2**。

- **体力**：26/30
- **引导进度**：2/3

> 下一步：`完成引导 炼丹`、`完成引导 炼器` 或 `完成引导 布阵`
```

```markdown
## 入道完成

**青云**已选择 **体修**，正式踏入修行之路。

- **境界**：感气境一层
- **灵石**：300
- **入道所得**：基础功法与对应试用技能

> 下一步：查看 `我的状态`
```

```markdown
## 修炼结算完成

**青云**获得 **修为 ×42**。

- **境界**：感气境一层（入门）
- **境内修为**：42/80
- **总修为**：42
- **体力**：28/30

> 下一步：继续发送 `开始修炼`，积累境内修为。
```

```markdown
## 过期修炼已恢复

**青云**按原始修炼快照完成了迟到结算。

- **恢复修为**：42
- **境界**：感气境一层（入门）
- **境内修为**：42/80
- **总修为**：42

> 这场修炼只会恢复结算一次；达到门槛后可发送 `晋升境界`。
```

```markdown
## 灵泉修炼已开始

**青云**已在灵泉谷开始灵泉修炼。

- **消耗体力**：3
- **剩余体力**：25/30
- **预计时长**：15 分钟
- **今日灵泉次数**：1/4

> 下一步：15 分钟后发送 `结算修炼`。
```

晋层命中 L3、L6、L9 或 L10 时，在基础结果后追加 `### 本层解锁` 列表。列表只展示
已实现资格或未来玩法预览，不展示稳定键，也不把预览写成已经开放的功能。
