# 运行与安全

## 1. 配置层级

配置分为三层：NoneBot 配置（`.env`/`.env.dev`）、插件运行配置（可由 Web
编辑的非密钥项）和进程环境变量（路径、端口、密钥、性能边界）。启动时输出
脱敏后的来源与最终值；同一键的优先级必须文档化，不允许模块自行猜测。

首版至少需要：

| 配置 | 作用 |
|:--|:--|
| `XIUXIAN3_DATA_DIR` | 数据、迁移、备份和缓存根目录 |
| `XIUXIAN3_WEB_ENABLED` / `XIUXIAN3_WEB_PORT` | Web 开关和端口 |
| `XIUXIAN3_WEB_SECRET_KEY` | 会话签名；缺失时安全生成并持久化 |
| `XIUXIAN3_WEB_ALLOWED_HOSTS` | Host 白名单 |
| `XIUXIAN3_ADMIN_IDS` | Web 管理员白名单，缺失时可回退 NoneBot superusers |
| `XIUXIAN3_TIMEZONE` | 业务日/周边界 |
| `XIUXIAN3_RATE_*` | 用户、群、全局限流边界 |
| `XIUXIAN3_QQ_CAPABILITIES` | 按 AppID 声明 Markdown、键盘、媒体等能力 |

所有密钥、QQ token、WebDAV 密码、NewAPI token 和用户身份数据只进运行目录，
不进入 Git、日志、错误响应或截图。

## 2. 定时任务

任务声明包含稳定 ID、显示名、触发器、时区、并发策略、超时、重试策略和是否
为关键资产任务。启动两次不能重复登记；手动运行使用独立 run id 并受同样权限
和幂等规则保护。

任务分组包括：每日/每周资源恢复、活动与世界事件、三界入口、洞天/福地清理、
市场订单清理与结算、消息清理、备份和健康检查。任何任务失败都要记录并可在
Web 查看，关键任务不能静默丢弃。

## 3. 备份与恢复

- 备份前记录 schema/规则版本、时间、数据目录和校验和。
- 备份文件只允许落在专用目录，下载前再次校验路径和权限。
- 恢复必须先停止写入、验证文件、创建当前快照，再执行恢复和迁移。
- 恢复后运行完整性检查、操作流水检查和一条只读冒烟；失败可回到恢复前快照。
- 云端同步是可选的，凭据通过 secret 管理，网络故障不能阻塞本地游戏。

## 4. 限流与队列

命令限流至少按用户、群/私聊场景和全局三层设置。非关键日志、缓存、统计可
在队列满时丢弃并计数；奖励、交易、战斗结算、迁移和恢复等关键任务必须等待
容量或同步完成，禁止静默丢失。

## 5. 安全底线

- 外部 URL 解析实施协议、DNS、内网地址、重定向、大小和超时限制。
- SQL 标识符、排序字段、路径和模板变量使用白名单，不能直接拼接用户输入。
- 管理操作记录操作者、原因、目标、前后摘要和 request/operation id。
- 生产日志和导出数据默认脱敏；测试夹具使用假身份和临时目录。
