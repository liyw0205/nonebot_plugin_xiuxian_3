# 玩家使用指南

本文适用于正式版本 `v0.1.39`。命令前缀由宿主 `COMMAND_START` 决定，示例中省略此前缀；QQ 群聊通常还需要 @机器人。QQ 可按平台能力提供蓝字或键盘，OneBot 使用对应的文本命令。

## 启程

新角色按以下顺序开始：

```text
开始修仙
寻仙问道
完成引导 阅读
我的状态
修仙帮助 启程
```

凡人引导会说明近郊采集与基础生产步骤。先用 `移动预览` 查看地点条件，再用 `前往 <地点>` 启程；行程结束后发送 `结算移动`。抵达后按引导完成采集、生产，再用 `选择道途 <道途>` 入道。道号可在创建时提供，也可通过 `修仙改名 <新道号>` 修改。

## 修炼与成长

```text
修仙帮助 修炼
我的状态
开始修炼
结算修炼
晋升境界
突破预览 <目标境界>
开始突破 <目标境界>
结算突破
```

修为足够时逐层晋升。跨越大境界前先预览并按要求准备资源；突破结果和恢复状态以服务端结算为准。境界、道途、功法、装备和任务会共同影响可用地点与玩法。

## 探索与剧情

```text
修仙帮助 探索
开始探索 <探索方式>
结算探索
主线道途
开始主线 <关卡名或序号>
领取主线奖励 <关卡名或序号>
引路簿
秘境预览
进入秘境 <秘境名>
```

先通过 `我的状态` 确认所在地，再在公开地点选择探索方式。探索奖励、遭遇战和图鉴只在结算后记录。主线状态会列出已解锁关卡与下一步提示；开始后完成该关目标，再领取主线奖励。目标未完成时关卡仍保留进行中，可按提示补足条件后重试。领域前线、虚空档案和其他剧情线各有独立状态命令，满足前置后可从 `修仙帮助 探索` 查看。

悬赏与常驻委托是不同入口：悬赏用 `悬赏榜`、`接取悬赏 <名称>` 和 `领取悬赏`；城镇物资委托用 `城镇委托`、`接取委托 <名称>`、准备指定物资后 `交付委托 <名称>`。查看目标和准入要求后再接取，进度只按本人已结算的服务端记录计算。

## 挂机与生活

```text
修仙帮助 生活
挂机预览 [路线名]
开始挂机 <路线名>
挂机状态
领取挂机
取消挂机
```

先查看路线的地点、门槛、投入、时长和完整/逾时所得。开始后可离线等待；满足领取窗口后领取，逾时则按该路线的保底结算。开始后 60 秒内可以取消并按规则退回投入。

地点专属路线须先真实抵达对应地点。云城店铺还要求 200 点云城名望；云铁矿区勘测派遣成功或部分完成后会结算名望，再在云城完整领取八小时店铺闲居。

生产使用 `生产预览 <配方名>`、`开始生产 <配方名>`、`生产状态` 与 `领取生产`。灵田使用 `灵田预览`、`灵田播种 <作物> <方案>`、`我的灵田` 和 `灵田收获`。运输、派遣、居所、公共项目、灵兽、市场和日常活动均有独立状态/预览入口；发送 `修仙帮助 生活` 可查看当前条件和可用命令。

例如，百草坡可从青石镇经近郊抵达。到达后用 `挂机预览 百草坡采药` 比较所得，再用
`开始挂机 百草坡采药` 安排四小时采药；结束后 `领取挂机`，止血草可用于药品和镇中物资委托。
需要短时补料时，可用 `开始探索 百草坡采集`，结束后 `结算探索`。采药、探索各有准入与日限，
委托另有有效期，备料前先查看各自状态。

日常用 `每日修行` 查看目标、`道历问安` 领取问安所得；功业用 `功业录` 查看、`领取功业 <序号>` 领取。
交易先查看 `摆摊列表`。灵兽用 `灵兽状态` 查看、`灵兽相伴 <灵兽编号>` 每日提升亲和，灵具制作与装备
分别使用 `生产预览` 和 `装备灵具`；器修可从 `机关` 查看组装、部署、收回和维修条件。

高阶角色可按所在地和资格继续使用以下流程：

| 玩法 | 查看与操作 |
|:--|:--|
| 虚空补给 | 抵达虚空集市后 `虚空集市` → `购买虚空物资 <物资名>` |
| 虚空寄售 | `虚空寄售` → `寄售物资 <物品> <数量> <单价>`，购买用 `购入寄售 <序号>`，撤回用 `撤下寄售 <序号>` |
| 终局天榜 | 抵达终局天榜后 `终局天榜` → `挑战天榜 <层级>` → `结算天榜` |
| 留界据点 | `据点` → `建立据点` 或 `加入据点`，随后按状态使用 `建设据点 <项目名>` 与 `维护据点`；据点需缴周维护费 |
| 宗门道统 | 六级宗门的合道修士用 `道统` 查看 → `道统投票 <守界|飞升|留界>` → 周日后 `道统结算` |
| 道侣协作 | `道侣协作` → `开始道侣协作` → `领取道侣协作` |
| 飞升日 | 赛季结束后 24 小时内用 `飞升日` 查看本届榜单、本人结局与新篇章入口 |

## 社交

```text
修仙帮助 社交
我的宗门
道侣关系
我的队伍
切磋 <道友名>
```

宗门、师徒、道侣、队伍和竞技活动各有资格、权限或邀请流程。使用状态命令查看本人关系；涉及其他玩家时按回复中的参数提示提交完整命令。直接切磋为不改变双方资产的即时战斗体验。

宗门用 `创建宗门` 或 `申请入宗` 开始，管理者用 `审批入宗` 处理申请；道侣邀请使用
`邀请结为道侣`，按回复补齐对象参数。组队后先完成成员确认，再由对应玩法入口发起活动。

## 使用提示

命令缺少参数时，优先根据回复提供的蓝字/按钮或参数提示继续。若地点、任务、境界或物资不足，先完成对应公开来源，不要通过其他命令模拟获得条件。游戏结果保存在宿主 SQLite；帮助、预览与状态查询不会消耗资产。

另见[当前可用能力](availability.md)和[安装指南](installation.md)。
