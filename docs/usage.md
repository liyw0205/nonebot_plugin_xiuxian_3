# 玩家使用指南

开发分支的山野勘察从 `山野手札` 开始：感气二层在近郊发送 `勘察地貌 溪崖石层`，按现场蓝字
选择做法，也可发送 `勘察抉择 溪崖石层 量痕探水`。稳妥做法多耗精力但必能查明，省力做法可能
失败，失败仍消耗体力；每次之后等待手札所示的查验间隔。`暂离勘察 溪崖石层` 保留进度，
回原地再发送勘察地貌即可继续。先查完溪崖，再到铁木林查根脉，最后聚气三层到玄武岩径查古渠；
首勘材料可循回复中的生产入口制作，重启后用手札接续，不会重复领取首勘奖励。

查明溪崖后用 `资源脉预览 溪崖药根`，再 `取用资源脉 溪崖药根 留根采叶` 或 `急取药丛`。
铁木与岩径对应 `倒木铁层`、`古渠砂窝`，具体做法以预览为准。每处六格储量，两小时自然恢复一格，
留养耗一格而强采耗三格；强采多得现成材料，但下一格最早也要三小时后恢复。实际扣除体力精力，
储量不足不会扣费。木材一、止血草一及四灵石，可在青石镇 `开始生产 护脉木楔`，三十秒后
`领取生产` 得两枚；回现场 `养护资源脉 溪崖药根` 消耗一枚补至多两格，每处每日两次。
只读预览不会刷新或保存储量，离线与重启仍按实际时间恢复，超过上限的时间不会积成额外库存。

本文列出常用命令流程。命令前缀由宿主 `COMMAND_START` 决定，示例中省略此前缀；QQ 群聊通常还需要 @机器人。实际可用入口以当前安装版本的 `修仙帮助` 与[当前可用能力](availability.md)为准；QQ 可按平台能力提供蓝字或键盘，OneBot 使用对应的文本命令。

QQ 回复中，详情、导航和待填参数通常显示为蓝字，确认、分页和完整操作通常显示为少量按钮；同一命令不会在正文和按钮中重复展示。未安装 QQ SDK 或账号缺少某项能力时，回复会自动降级为可读 Markdown 或普通文本，仍保留可直接发送的命令。OneBot 始终使用同一业务结果的纯文本版本；示例命令是否带前缀只由宿主配置决定，回复正文不会强行显示 `/` 或 `!`。

## 启程

新角色按以下顺序开始：

```text
开始修仙
寻仙问道
完成引导 阅读
我的状态
修仙帮助 启程
```

凡人引导会说明近郊采集与基础生产步骤。先用 `移动预览` 查看地点条件，再用 `前往 <地点>` 启程；行程结束后发送 `结算移动`。抵达后按引导完成采集、生产，再用 `选择道途 <道途>` 入道。道号可在创建时提供，也可通过 `修仙改名 <新道号>` 修改。

## 修炼与成长

```text
修仙帮助 修炼
我的状态
开始修炼
结算修炼
晋升境界
突破预览 <目标境界>
开始突破 <目标境界>
结算突破
```

修为足够时逐层晋升。跨越大境界前先预览并按要求准备资源；突破结果和恢复状态以服务端结算为准。境界、道途、功法、装备和任务会共同影响可用地点与玩法。

## 探索与剧情

```text
修仙帮助 探索
开始探索 <探索方式>
结算探索
主线道途
开始主线 <关卡名或序号>
领取主线奖励 <关卡名或序号>
引路簿
秘境预览
进入秘境 <秘境名>
```

先通过 `我的状态` 确认所在地，再在公开地点选择探索方式。探索奖励、遭遇战和图鉴只在结算后记录。主线状态会列出已解锁关卡与下一步提示；开始后完成该关目标，再领取主线奖励。目标未完成时关卡仍保留进行中，可按提示补足条件后重试。领域前线、虚空档案和其他剧情线各有独立状态命令，满足前置后可从 `修仙帮助 探索` 查看。

悬赏与常驻委托是不同入口：悬赏用 `悬赏榜`、`接取悬赏 <名称>` 和 `领取悬赏`；城镇物资委托用 `城镇委托`、`接取委托 <名称>`、准备指定物资后 `交付委托 <名称>`。查看目标和准入要求后再接取，进度只按本人已结算的服务端记录计算。

### 山路巡查

`悬赏榜` 每日按境界随机列出三条可接合同；近郊、铁木林与岩径各有单程（一次巡查、两小时内）和双程（两次巡查、三小时内）委托，每张合同每日可接一次。先 `接取悬赏 <合同名>`，再开始本人的新路线；接单前的行程不计，取消、逾时、失败或战败也不计，达标后用 `领取悬赏` 领取接单时已冻结的灵石、材料与名望。悬赏不会收走巡查本身的材料；路线成本、每日四次上限与稳行/追迹规则不变，每日巡查余次不足时不再提供对应合同，跨日可重新查看。

`巡查预览` 展示三条路线与可重复遇见的九种路况；`巡查预览 近郊巡路` 可只看一处。
近郊巡路在玄天近郊要求感气二层，铁木巡林在铁木林要求感气四层，岩径巡标在玄武岩径要求聚气三层。
实际抵达后使用 `开始探索 近郊巡路 稳行` 或 `开始探索 近郊巡路 追迹`，其他路线同理。
省略方案使用稳行，每条每日四次；出发时确定事件与收成，重复请求不重新抽取。

稳行花三分钟（岩径四分钟）、体力四与精力一（岩径六与二），遇战率百分之十五（岩径二十五）。

地点专属路线须先真实抵达对应地点。云城店铺还要求 200 点云城名望；云铁矿区勘测派遣成功或部分完成后会结算名望，再在云城完整领取八小时店铺闲居。

生产使用 `生产预览 <配方名>`、`开始生产 <配方名>`、`生产状态` 与 `领取生产`。灵田使用 `灵田预览`、`灵田播种 <作物> <方案>`、`我的灵田` 和 `灵田收获`。运输、派遣、居所、公共项目、灵兽、市场和日常活动均有独立状态/预览入口；发送 `修仙帮助 生活` 可查看当前条件和可用命令。

例如，百草坡可从青石镇经近郊抵达。到达后用 `挂机预览 百草坡采药` 比较所得，再用
`开始挂机 百草坡采药` 安排四小时采药；结束后 `领取挂机`，止血草可用于药品和镇中物资委托。
需要短时补料时，可用 `开始探索 百草坡采集`，结束后 `结算探索`。采药、探索各有准入与日限，
委托另有有效期，备料前先查看各自状态。

日常用 `每日修行` 查看目标、`道历问安` 领取问安所得；功业用 `功业录` 查看、`领取功业 <序号>` 领取。
交易先查看 `摆摊列表`。灵兽用 `灵兽状态` 查看、`灵兽相伴 <灵兽编号>` 每日提升亲和，灵具制作与装备
分别使用 `生产预览` 和 `装备灵具`；器修可从 `机关` 查看组装、部署、收回和维修条件。

高阶角色可按所在地和资格继续使用以下流程：

| 玩法 | 查看与操作 |
|:--|:--|
| 虚空补给 | 抵达虚空集市后 `虚空集市` → `购买虚空物资 <物资名>` |
| 虚空寄售 | `虚空寄售` → `寄售物资 <物品> <数量> <单价>`，购买用 `购入寄售 <序号>`，撤回用 `撤下寄售 <序号>` |

## 社交

```text
修仙帮助 社交
我的宗门
道侣关系
我的队伍
切磋 <道友名>
```

宗门、师徒、道侣、队伍和竞技活动各有资格、权限或邀请流程。使用状态命令查看本人关系；涉及其他玩家时按回复中的参数提示提交完整命令。直接切磋为不改变双方资产的即时战斗体验。

宗门用 `创建宗门` 或 `申请入宗` 开始，管理者用 `审批入宗` 处理申请；道侣邀请使用
`邀请结为道侣`，按回复补齐对象参数。组队后先完成成员确认，再由对应玩法入口发起活动。

已有有效道侣可使用 `双修预览` 检查共同地点、本人可得修为、各自成本与今日 UTC 次数，再由一方发送
`发起双修 <道号>`，另一方用收到的邀请号 `接受双修 <邀请号>` 或 `拒绝双修 <邀请号>`；发起者可在接受前
发送 `取消双修 <邀请号>`。每次接受都重新核验双方状态，只有成功时才分别扣费和增加个人修为；失败不会
扣除任一方资源。使用 `双修状态` 查看本人邀请及当前资格。两人必须在同一开放的共修地点，不能正处于
修炼、探索、生产、战斗或其他锁定行动中。完整成本、额度、期限与修为边界以[共修合同](gameplay/social/dual-cultivation.md)为准。

### 云舟合力护航

金丹一层起，四至五名修士实际抵达云舟渡口后，可共同迎战云舟守灵。
先发 `多人副本预览`（或 `队伍战备`），查看每人的地点、境界、确认、体力精力、
今日次数与其他行程；此查询不扣费。队长用 `创建多人副本队伍`，再用
`邀请入队 qq.official:用户ID` 或 `邀请入队 onebot.v11:用户ID` 邀请同地点道友。
受邀者发送 `接受入队 队伍号`，每名成员发送 `确认入队 队伍号`；确认窗口到期须重新集结。
队长用 `开始队伍战斗` 开战，双人队伍不能替代四人队伍。

云舟守灵每次对全员各收十二体力、三精力，每人每日最多出战三次，UTC 零时重置；
更换队伍或重启不重置个人次数。所有成员条件通过后才一并扣费，缺资源、人数不足、
境界或地点不符、未确认、确认过期及其他行程占用均不会部分扣费。
开战即计次，战败或超时不退入场消耗且不发胜利材料；战斗采用开战时的装备和奖励。

胜利且取得贡献的每名成员得到一百修为、四十灵石、一份云铁和一份阵砂，
结算逐人列出实际所得。连续两胜的两份云铁、一份阵砂可以经云城返回青石镇后，
用 `接取委托 候潮备材`、`交付委托 候潮备材` 实际交出，换取六十五灵石与五点镇中名望。
委托截止仍为 UTC 当日公示后十二小时，先看 `城镇委托` 再接，过期次日重接；
余料可用 `生产预览 云纹剑`、`生产预览 基础聚灵阵` 查看炼器或布阵用途。
此交单可以独立完成；云舟候潮主线仍须满足该关新接订单等原有证据条件。

断线后任一参战成员可发 `结算队伍战斗 战斗编号` 接续，
用 `队伍战斗回放 战斗编号` 查看战局。内容关闭或改值后，合法旧战斗仍按冻结快照结算；
重复、并发结算不重复发物。QQ 官方与 OneBot V11 使用同一入口，
QQ 消息能力降级时保留文本命令；模拟验证不代表真实账号投递验收。

### 玄武岩径古渠守标

聚气二层起，四至五名道友抵达玄武岩径后可挑战古渠守标。先用 `多人副本预览` 查看
成员地点、境界、确认、体力精力、UTC 当日次数与其他行程；再按云舟合力护航的相同组队流程
邀请、接受并全员确认，队长用 `开始队伍战斗` 发起。每人每日一次，支付十体力与二精力；
全员校验后才一起扣费，战败或超时计次且不退款。胜利且有贡献者各得七十五修为、二十八灵石、
铁石和阵砂各一份。铁石可用于 `生产预览 野外修缮包`，阵砂可用于
`生产预览 山河罗盘` 或 `生产预览 基础聚灵阵`；缺料时可在玄武岩径采集或从公开交易取得。
断线后任一参战成员可结算并查看回放；重复结算重放原结果。正式可用范围以当前可用能力页为准。

## 使用提示

命令缺少参数时，优先根据回复提供的蓝字/按钮或参数提示继续。若地点、任务、境界或物资不足，先完成对应公开来源，不要通过其他命令模拟获得条件。游戏结果保存在宿主 SQLite；帮助、预览与状态查询不会消耗资产。

另见[当前可用能力](availability.md)和[安装指南](installation.md)。
