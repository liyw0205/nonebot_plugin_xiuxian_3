# 玩家使用指南

本文列出常用命令流程。命令前缀由宿主 `COMMAND_START` 决定，示例中省略此前缀；QQ 群聊通常还需要 @机器人。实际可用入口以当前安装版本的 `修仙帮助` 与[当前可用能力](availability.md)为准；QQ 可按平台能力提供蓝字或键盘，OneBot 使用对应的文本命令。

## 启程

新角色按以下顺序开始：

```text
开始修仙
寻仙问道
完成引导 阅读
我的状态
修仙帮助 启程
```

凡人引导会说明近郊采集与基础生产步骤。先用 `移动预览` 查看地点条件，再用 `前往 <地点>` 启程；行程结束后发送 `结算移动`。抵达后按引导完成采集、生产，再用 `选择道途 <道途>` 入道。道号可在创建时提供，也可通过 `修仙改名 <新道号>` 修改。

## 修炼与成长

```text
修仙帮助 修炼
我的状态
开始修炼
结算修炼
晋升境界
突破预览 <目标境界>
开始突破 <目标境界>
结算突破
```

修为足够时逐层晋升。跨越大境界前先预览并按要求准备资源；突破结果和恢复状态以服务端结算为准。境界、道途、功法、装备和任务会共同影响可用地点与玩法。

## 探索与剧情

```text
修仙帮助 探索
开始探索 <探索方式>
结算探索
主线道途
开始主线 <关卡名或序号>
领取主线奖励 <关卡名或序号>
引路簿
秘境预览
进入秘境 <秘境名>
```

先通过 `我的状态` 确认所在地，再在公开地点选择探索方式。探索奖励、遭遇战和图鉴只在结算后记录。主线状态会列出已解锁关卡与下一步提示；开始后完成该关目标，再领取主线奖励。目标未完成时关卡仍保留进行中，可按提示补足条件后重试。领域前线、虚空档案和其他剧情线各有独立状态命令，满足前置后可从 `修仙帮助 探索` 查看。

悬赏与常驻委托是不同入口：悬赏用 `悬赏榜`、`接取悬赏 <名称>` 和 `领取悬赏`；城镇物资委托用 `城镇委托`、`接取委托 <名称>`、准备指定物资后 `交付委托 <名称>`。查看目标和准入要求后再接取，进度只按本人已结算的服务端记录计算。

### 云城店铺回响

金丹一层可用 `云城店铺回响主线` 查看进度。每关先开始，再完成本人新产生的目标，最后领取该关奖励：

| 关卡 | 开始 | 目标 | 领奖 |
|:--|:--|:--|:--|
| 云城听更 | `开始云城店铺回响主线 云城听更` | 沿公开相邻路线 `前往 云城`，等待后 `结算移动` | `领取云城店铺回响主线奖励 云城听更` |
| 巡夜见锋 | `开始云城店铺回响主线 巡夜见锋` | 身在云城 `开始探索 云城巡夜`，等待后 `结算探索`，须赢得一场遭遇战 | `领取云城店铺回响主线奖励 巡夜见锋` |
| 店铺交班 | `开始云城店铺回响主线 店铺交班` | 身在云城且名望达到 200 后 `开始挂机 云城店铺`；八小时后在完整领取窗口内 `领取挂机` | `领取云城店铺回响主线奖励 店铺交班` |

名望不足时可先 `派遣预览 云铁矿区勘测`，备齐投入后在云城 `接受派遣 云铁矿区勘测`，到时 `结算派遣`；成功增加 5 点、部分完成增加 2 点云城名望，失败不增加。重复积累须遵守派遣自己的每日次数和资源要求。再用 `挂机预览 云城店铺` 确认准入与领取时间。

旧行程、旧胜场和本关开始前的挂机安排不计目标。巡夜未遇敌或战败时按原日限重试；挂机取消或逾时保底不能完成交班，先处理现有安排，再在额度允许时新建。主线和挂机进度保存在服务端；离线或宿主重启后，可分别用 `云城店铺回响主线` 与 `挂机状态` 接续，不必重新开始。

### 妖界栖地回响

完成万兽山 cap 层主线并持有妖界引路资格后，可用 `妖界栖地回响主线` 查看三段后记。每关先开始，再完成本人新产生的目标，最后领取奖励：

| 关卡 | 开始 | 目标 | 领奖 |
|:--|:--|:--|:--|
| 贸易口登记 | `开始妖界栖地回响主线 贸易口登记` | 从万兽山 `前往 三界贸易口`，等待后 `结算移动` | `领取妖界栖地回响主线奖励 贸易口登记` |
| 夜巡取证 | `开始妖界栖地回响主线 夜巡取证` | 回到万兽山，`开始探索 万兽山狩猎`，结算并取得本人新兽血 | `领取妖界栖地回响主线奖励 夜巡取证` |
| 妖界栖地夜值 | `开始妖界栖地回响主线 妖界栖地夜值` | 完成妖界引导、备妥 80 点妖界声望和 500 灵石后 `申请贸易许可 妖界`；用 `挂机预览 妖界栖地`、`开始挂机 妖界栖地`，八小时后完整 `领取挂机` | `领取妖界栖地回响主线奖励 妖界栖地夜值` |

旧行程、旧库存、逾时保底、取消、探索战败或未结算记录均不推进主线。主线、许可和挂机会在服务端保存；重启后用 `妖界栖地回响主线` 与 `挂机状态` 恢复，按原路线和日限重试。

### 灵兽旧兽道回响

完成玄天主线“初入玄天”后，可用 `灵兽旧兽道回响主线` 查看近郊三关。每关先开始，再完成本关的新目标，最后领取奖励：

| 关卡 | 开始 | 目标 | 领奖 |
|:--|:--|:--|:--|
| 近郊结缘 | `开始灵兽旧兽道回响主线 近郊结缘` | 本关开始后 `结缘灵兽 木鼠`，或与已有木鼠 `灵兽相伴 编号` | `领取灵兽旧兽道回响主线奖励 近郊结缘` |
| 四时巡护 | `开始灵兽旧兽道回响主线 四时巡护` | 在近郊用已结缘灵兽安排 `灵兽栖地巡护`，四小时后完整 `领取挂机` | `领取灵兽旧兽道回响主线奖励 四时巡护` |
| 灵米喂伴 | `开始灵兽旧兽道回响主线 灵米喂伴` | 用完整巡护所得的粗糙灵米 `喂养灵兽 <灵兽编号>` | `领取灵兽旧兽道回响主线奖励 灵米喂伴` |

新结缘须来自已完成的玄天“初入玄天”记录。用 `灵兽状态` 查看编号及喂养、相伴入口；结缘满额时可与已有木鼠相伴，相伴每日一次且消耗体力。木鼠已蜕变为铁背鼠或玉背鼠时，同样可以相伴、巡护与喂养。旧结缘、旧相伴和旧喂养不推进关卡；取消、逾时保底或尚未结算的巡护也不算完整交班。可在 `修仙帮助 生活` 查看关联入口；主线与挂机状态在重启后保留，完成条件后可按路线原日限重试。

### 泉边炊烟

感气二层后，可用 `泉边炊烟主线` 查看两关。先 `开始泉边炊烟主线 泉畦拾穗`，从青石镇沿山路
`前往 灵泉谷`，确认 `挂机预览 灵泉谷拾穗` 后安排四小时拾穗，完整 `领取挂机` 才能
`领取泉边炊烟主线奖励 泉畦拾穗`。取消或逾时只留的干米不算完整收成，按路线日限重试即可。

再 `开始泉边炊烟主线 一饭暖途`。这一餐需要烹饪辅修，其他辅修可先 `辅修预览 烹饪` 查看原有切换条件。
用拾穗取得的两份粗糙灵米 `开始生产 灵米饭`，十五秒后
`领取生产`。出饭后选择 `使用物品 灵米饭 体力` 或 `使用物品 灵米饭 精力`，实际补回气力后
`领取泉边炊烟主线奖励 一饭暖途`。本关开始前开的锅或吃过的饭都不计入，气力已满时可先继续旅途或劳作。
主线、稻畦和锅灶会保留进度；重启后查看主线、`挂机状态` 与 `生产状态`，生产逾时按原恢复规则处理。
`修仙帮助 生活` 提供关联入口。

## 挂机与生活

```text
修仙帮助 生活
挂机预览 [路线名]
开始挂机 <路线名>
挂机状态
领取挂机
取消挂机
```

先查看路线的地点、门槛、投入、时长和完整/逾时所得。开始后可离线等待；满足领取窗口后领取，逾时则按该路线的保底结算。开始后 60 秒内可以取消并按规则退回投入。

地点专属路线须先真实抵达对应地点。云城店铺还要求 200 点云城名望；云铁矿区勘测派遣成功或部分完成后会结算名望，再在云城完整领取八小时店铺闲居。

生产使用 `生产预览 <配方名>`、`开始生产 <配方名>`、`生产状态` 与 `领取生产`。灵田使用 `灵田预览`、`灵田播种 <作物> <方案>`、`我的灵田` 和 `灵田收获`。运输、派遣、居所、公共项目、灵兽、市场和日常活动均有独立状态/预览入口；发送 `修仙帮助 生活` 可查看当前条件和可用命令。

例如，百草坡可从青石镇经近郊抵达。到达后用 `挂机预览 百草坡采药` 比较所得，再用
`开始挂机 百草坡采药` 安排四小时采药；结束后 `领取挂机`，止血草可用于药品和镇中物资委托。
需要短时补料时，可用 `开始探索 百草坡采集`，结束后 `结算探索`。采药、探索各有准入与日限，
委托另有有效期，备料前先查看各自状态。

日常用 `每日修行` 查看目标、`道历问安` 领取问安所得；功业用 `功业录` 查看、`领取功业 <序号>` 领取。
交易先查看 `摆摊列表`。灵兽用 `灵兽状态` 查看、`灵兽相伴 <灵兽编号>` 每日提升亲和，灵具制作与装备
分别使用 `生产预览` 和 `装备灵具`；器修可从 `机关` 查看组装、部署、收回和维修条件。

高阶角色可按所在地和资格继续使用以下流程：

| 玩法 | 查看与操作 |
|:--|:--|
| 虚空补给 | 抵达虚空集市后 `虚空集市` → `购买虚空物资 <物资名>` |
| 虚空寄售 | `虚空寄售` → `寄售物资 <物品> <数量> <单价>`，购买用 `购入寄售 <序号>`，撤回用 `撤下寄售 <序号>` |
| 终局天榜 | 抵达终局天榜后 `终局天榜` → `挑战天榜 <层级>` → `结算天榜` |
| 留界据点 | `据点` → `建立据点` 或 `加入据点`，随后按状态使用 `建设据点 <项目名>` 与 `维护据点`；据点需缴周维护费 |
| 宗门道统 | 六级宗门的合道修士用 `道统` 查看 → `道统投票 <守界|飞升|留界>` → 周日后 `道统结算` |
| 道侣协作 | `道侣协作` → `开始道侣协作` → `领取道侣协作` |
| 飞升日 | 赛季结束后 24 小时内用 `飞升日` 查看本届榜单、本人结局与新篇章入口 |

## 社交

```text
修仙帮助 社交
我的宗门
道侣关系
我的队伍
切磋 <道友名>
```

宗门、师徒、道侣、队伍和竞技活动各有资格、权限或邀请流程。使用状态命令查看本人关系；涉及其他玩家时按回复中的参数提示提交完整命令。直接切磋为不改变双方资产的即时战斗体验。

宗门用 `创建宗门` 或 `申请入宗` 开始，管理者用 `审批入宗` 处理申请；道侣邀请使用
`邀请结为道侣`，按回复补齐对象参数。组队后先完成成员确认，再由对应玩法入口发起活动。

## 使用提示

命令缺少参数时，优先根据回复提供的蓝字/按钮或参数提示继续。若地点、任务、境界或物资不足，先完成对应公开来源，不要通过其他命令模拟获得条件。游戏结果保存在宿主 SQLite；帮助、预览与状态查询不会消耗资产。

另见[当前可用能力](availability.md)和[安装指南](installation.md)。
